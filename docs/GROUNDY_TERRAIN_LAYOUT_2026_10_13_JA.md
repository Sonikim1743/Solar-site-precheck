# 地番・3D地形・参考配置の検討記録

2026年10月13日。対象は Solar Site Precheck の開発ブランチ `feat/terrain-layout-preview`。本書は調査と今回の実装範囲をまとめたもので、公開更新の完了記録ではありません。配布・公開・最終検証は別のリリース記録で確認します。

## 今回の目的

地図で土地を探し、検討範囲と除外を決め、同じ範囲の地形を見て、SolarPro・CADで詳しく検討する流れを短くします。新しい画面や説明カードを増やさず、既存の地図と折りたたみ式の地形欄に必要な操作を置きます。

今回の参考配置は「この形・向き・間隔で何枚の形が収まるか」を確かめる補助です。配置比較の中で最も枚数の多い参考案を選びますが、数学的な最大配置、設置可能容量、系統連系、基礎、日影、造成、施工可否の判定には使いません。

## Groundyで確認できたこと

[Groundy](https://groundy.net/)の公開クライアント資料と、ブラウザーで実際に切り替えた3D表示を調査しました。

| 確認項目 | 得られた根拠と限界 |
| --- | --- |
| 地形表示 | 地形用の `raster-dem` と Mapbox の地形データを指定する処理を確認しました。地図の3D表示も実画面で確認しました。 |
| 指定値 | データ識別子は `mapbox-terrain-dem-v1`、タイル寸法512、最大データズーム14。3D側は高さ強調1.5、画面の傾き80°を指定する処理でした。タイル寸法やズーム値は測量精度を意味しません。 |
| 解析の範囲 | 地形初期化に関する225バイトの関数断片について、REAの構文解析が成功しました。外部の地図オブジェクトに依存するため意味解析は部分的です。 |
| 未確認 | 大きなスクリプト全体の解析は成功していません。全機能、内部データ処理、サーバー側、すべての操作条件を解明したとは扱いません。 |

Mapboxの公式例でも、DEMを地形として指定し、高さを強調する方法が示されています。[Mapbox公式「Add 3D terrain」](https://docs.mapbox.com/mapbox-gl-js/example/add-terrain/)
MapLibreにも連続する地図の3D地形表示例があります。これは今後の比較材料で、今回の地図エンジン変更を意味しません。[MapLibre公式「3D Terrain」](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)

公開用の本書には、第三者の取得スクリプト、認証情報、非公開の画面、個別案件の座標や資料を含めません。

## 当アプリとの違いと採用方針

| 観点 | Groundyの今回確認した表示 | 当アプリの今回の方針 |
| --- | --- | --- |
| 見る範囲 | 航空写真などを載せた、周辺へ連続する3D地図 | 指定した有効範囲を切り出した国土地理院DEMの立体図 |
| 主な用途 | 土地と周辺の位置関係を連続的に見る | 同じ範囲の等高線・勾配・高低差と次の確認事項を結ぶ |
| 立体表示 | 地図の傾きと高さ強調を利用 | 直交投影のブロック表示。底面・側面は表示用で、地層や土量を示さない |
| 数値との関係 | 今回の調査では他の数値計算までは確認していない | 表示倍率を変えても元の標高・勾配・参考配置枚数は変更しない |

まず当アプリの同じ範囲を追える長所を維持し、地番へのアクセスと参考配置を改善します。連続する航空写真3Dへの置き換えは今回の範囲に含めません。

## 今回の操作と条件

1. 地図上の **「地番 ON／OFF」** で公開地番を直接切り替えます。レイヤーメニュー内の重複操作はなくし、表示状態を一つにします。表示を消しても対象の筆、検討範囲、除外は保持します。
2. 有効範囲の地形を取得した後、**「3D地番 ON／OFF」** で実際の資料にある地番と参考線を重ねます。読み込んだ筆の資料と、地図で取得した公開地番を利用します。住所から番号を推測しません。
3. **「自動で参考配置」** で選択した勾配条件の地形に参考架台を並べます。利用者の最終確認により、1架台は**4段固定 × 4〜8列**の16〜32枚です。狭い場所では列数の少ない架台を使い、同じ向きの行に並べます。基準方位の±30°と開始位置を最大12案比較し、枚数、支持高さの小ささ、基準方位への近さの順で参考案を選びます。最大枚数・発電量の最適性・施工適性を保証する探索ではありません。
   計算後は **図のすぐ下の「減らす／増やす」** で候補の架台を一つずつ除き、同じ位置へ戻します。全候補が表示中の「増やす」は無効です。**「参考配置 ON／OFF」** は図だけを切り替え、枚数と計算結果を保持します。
   平面図・3Dの青い架台をクリックすると、その架台だけを除外できます。残る点線をクリックして同じ位置へ戻します。架台を選んでも他の位置は詰め直さず、枚数・DC・ACと配置面積だけを再集計します。3Dでは5pxを超えるドラッグを回転として扱い、選択を変えません。キーボードでも架台に移動してEnter・空白キーで切り替えられます。
4. 上段は **参考配置・最適配置の比較・勾配** の操作に絞り、下の小さな操作欄に **「配置条件」「3D地番」「?」** を置きます。列数、方位、パネル傾斜、左右・前後・端の空きは「配置条件」で編集し、変更後は再計算します。実寸・計算方法・未判定事項・保存範囲の説明は「?」のダイアログで確認します。枚数・DC・AC、計算中・上限到達・0架台の状態は画面上で確認できます。単に表示をOFFにした場合は、条件と計算結果を保持します。
5. **勾配10°未満／15°未満／20°未満**で配置例を比較します。配置後に切り替えると、その条件で再計算し個別除外を初期化します。色区分は同じままです。15°・20°を選ぶことは施工可能との判断ではありません。
6. **「最適配置を比較」** は基準方位±30°の9方向（7.5°刻み）と1/4・1/2・3/4の開始位置を最大32案・24,000候補・8秒で比較します。同じ分析・条件の既存案は保持し、時間切れでも枚数の少ない案に置き換えません。「中止」で止められます。
7. 配置条件の端の空きの横にある **「配置を囲むフェンス」** は、選択中のモジュール架台の平面外形をまとめた一つの凸包（全体を包む外形）から作ります。その外側に **「端からの空き」と同じ実距離（内部値 `setbackM`）** をメートル単位で取り、有効範囲との共通部分だけを残して、高さ1.2mの参考線と支柱を表示します。離れた架台の間も一緒に囲みます。除外した架台は囲いを作る点群から外し、復元すると再び含めます。全架台を除外した場合や配置がない場合はフェンスを作りません。内側の除外に追加の囲いを付けず、欠測区間をつなぎません。実測境界・施工線・フェンス設計を示すものではなく、配置枚数も変更しません。

現在の参考プリセットは横置き720W、外形2.384 × 1.303m、モジュール間20mm、パネル傾斜10°、左右の空き1m、前後4m、端から1m、地表から最低0.8mです。これらは初期の検討条件で、推奨設計値や現地で確認した寸法ではありません。別製品・縦置きへ変更する場合は、出力だけでなく外形と配置条件を一緒に見直します。

4列の幅は9.596m、8列の幅は19.212mです。4段のパネル面奥行は5.272m、傾斜10°での水平奥行は約5.1919mです。図形は地形と同じAEQDメートル座標で作り、装飾用ピクセルの大きさで配置しません。メーカー66HL5-BDVの公開資料の外形も2384×1303×33mmであることを再確認しました。地域・改訂接尾辞の違う資料なので、電気特性まで同一とは扱いません。[外形のメーカー資料](https://www.jinkosolar.com/uploads/694e4ad2/JKM710-735N-66HL5-BDV-Z4-CN.pdf)

緑の判定は、画面と同じ5mセルの四隅にある局所勾配の平均が10°未満であることです。元の局所勾配は10m幅で計算しています。参考配置の初期条件も10°未満で、15°・20°未満を選択できます。選択した角度ちょうどのセルは含みません。緑色や条件選択は施工できる土地を意味しません。架台全体と指定した空きが有効範囲・選択した勾配条件に収まり、除外や欠測にかからないものを数えます。QB、進入路、残す樹木などの予約場所は、配置前に除外として指定します。

DCは枚数×720Wです。ACはDC÷1.5の値を、100kW以下では10kW、超える場合は50kW単位で丸めた目安です。**計算方法だけの例**としてDC500kWなら丸め前は約333kW、表示の目安は350kWです。丸め後のDC/AC比は厳密に150%にはならず、PCSの選定・受電条件・連系承諾を示しません。

架台は地表に合わせて折れ曲がる面にせず、架台ごとに一つの平面として置きます。地表との空きは表示上の仮定です。高さ2倍は視認用の強調で、実寸や支持物の必要高さを読むときは1:1で確認します。高さ強調をしても枚数・DC・ACは変わりません。

## 公開地番・地形の扱い

- 密集する地番は中心だけに固定せず、地図では筆の内部の別位置と短い引出線の候補を比較します。長い番号も省略せず折り返します。全候補が重なるときは拡大して確認します。データがない場合と文字が重なる場合は別の問題です。
- 平面図・3Dは最大30の実番号を、画面内の近い空きへ最大140表示座標以内で移動します。移動した番号は細い線と元位置の点で結び、文字を線より上に描きます。収まらない番号・現在の視点で地形の裏側にある番号は折りたたみ一覧へ残します。番号の移動は筆界・DEM・面積の変更ではなく、参考モジュールも番号を消しません。
- 公開地番は法務省地図データを加工した2024年の公開タイル資料です。タイル境界で切れた部分図形が含まれ、登記面積・所有関係・測量筆界を確認する資料として自動採用しません。[公開資料の出典](https://source.coop/smartmaps/amx-2024-04)
- 3D用には地図が実際に要求したタイルを再利用します。別の地域を自動収集する処理は追加しません。上限は32元タイル、80図形、8,000頂点で、部分取得・上限到達を区別します。
- 同じ地番文字だけでは筆を統合しません。同一図形の重複を除き、穴・分離した面を保持し、地形の有効範囲に重なる部分だけを表示します。読込資料と公開資料が重なる場合は読込資料を優先します。
- 地図の地番をOFFにしても、取得済みの参考データは独立した3D表示用に保持します。位置変更・地図移動中の古い非同期応答を採用せず、範囲外の図形は新しい地形へ移し替えません。
- 国土地理院DEMの原資料は1m・5m・10m級が混在することがあります。表示・集計格子5mは原資料の精度を上げる処理ではありません。欠測・中抜き・除外を埋めません。[国土地理院の標高タイル](https://maps.gsi.go.jp/development/demtile.html)
- 今回の配置・地番重ね表示は画面の検討補助です。既存の地形報告書は固定した二つの視点と1:1を保持し、画面の参考容量を施工確定値として報告書へ自動転記しません。

## 次に確認する順序

| 優先 | 確認する仕事 | 完了の目安 |
| --- | --- | --- |
| P0 | 地図→範囲・除外→地形→地番・参考配置→報告書の実操作 | モバイルを含め上段操作・図下の増減・「?」の開閉が使え、表示OFF・画面往復で入力を失わない。個別除外・復元で枚数と囲いが追従し、0架台・欠測・計算上限を誤読しない。実操作結果は別のQA記録へ残す。 |
| P0 | Macで同じコードと合成記録を開く | Safariを含め3D操作、Worker計算、取消、地図表示、PDF、記録の再開を実機確認する。Windowsの合格をMacの合格に置き換えない。 |
| P1 | 三つの業務試行で次の作業につながるか確認 | 過去の二つの非公開内部例と、共有条件を確認した匿名・合成資料を使う。検討時間、根拠の欠落、初見の理解、SolarPro/CADへの再利用を実測する。個別資料は公開リポジトリに入れない。 |
| その後 | 有料資料としての価値を判断 | 無料の地図・範囲・地形確認を土台とし、条件整理・比較資料・日本語報告書の時間節約に需要があるか試す。購入意向、節約時間、価格は未検証として扱う。 |

# 規制の初期確認と回答メモ（開発中）

「検討区域」をONにすると、選択地点について発電量検討の前に確認する条件を表示します。用途地域・用途制限と計画設備の設置可否を先頭に置き、農地・農振区分、参考区域、洪水・土砂を確認します。各項目の「次の確認・窓口・回答メモ」から質問と公式情報を参照できます。現在の重なり照合は地点のみで、敷地全体の判定ではありません。

## 今回の範囲

- 用途地域の区域資料と計画用途の適合性は未取得・未判定として明示します。資料が空、未収録、失敗した場合も非該当や設置可能とはしません。特定の面積値を全用途や敷地面積へ一律に当てはめません。正式な用途地域・地区計画等、設備の用途分類、対象面積と根拠、必要な手続を管轄へ確認します。
- 筆ごとの農地・青地・白地の取得は未対応です。既存の農業地域や古い農用地区域との重なりを農地の確定判定へ置き換えません。農地は一律に除外しません。
- 保安林・国有林、盛土・砂防等、都市計画、津波・高潮は未確認の条件として表示します。新しい区域データやEneMapの内部APIは取り込んでいません。
- 重なりがある場合も、一部資料の未収録・透明・失敗を隠しません。未検出・未確認・資料なしは規制なしや安全の証明ではありません。
- 現在の表示と計算結果を維持します。発電量の実行を自動禁止したり、開発可否を自動決定したりする変更はありません。

## 相談から次の検討へ

項目ごとに質問、確認した窓口、確認日、回答と残る条件を記録します。状態は未相談・回答待ち・回答記録済み・保留・見送りです。「回答記録済み」は許可取得や条件解消を意味しません。該当情報を消さず、回答を踏まえて次の検討を判断します。

メモは正確な選択地点の座標ごとに画面内で保持し、別地点へ混在させません。画面の開閉・再確認・発電量や系統画面との往復では保持します。ブラウザー再読み込み前に「確認メモを保存」で専用JSONを保存してください。自動保存・外部送信は行いません。既存の検討記録schema 1/2/3とは別ファイルです。

「確認メモを開く」は64KB以下の専用JSONを検証し、地点が完全一致する場合に反映前の確認を表示します。反映するまで既存のメモを変更しません。ファイル内のURLや判定は取り込まず、文字列は通常のテキストとして扱います。実案件のメモは公開ソースに含めないでください。

## 比較の根拠と残る課題

[国土交通省の用途地域の説明](https://www.kkr.mlit.go.jp/kensei/town/tosi/03yototiiki.html)と[太陽光・蓄電池等の技術的助言一覧](https://www.mlit.go.jp/jutakukentiku/jutakukentiku_house_fr_000039.html)を確認しています。店舗等の一般的な面積制限から、個別の太陽光・蓄電池計画の設置可否は推定しません。都市計画決定GIS・XKT002等は将来の資料候補であり、今回API接続・キー発行・データ取得をしていません。取得する場合は利用条件・収録範囲・基準日・位置精度を確認し、空応答も未確認として扱います。

EneMapの実画面で条件別の規制確認、許認可案内、管轄窓口と未収録情報を確認しました。[公開出典一覧](https://enemap.app/data-sources)は2026-07-11更新で、農業委員会レイヤーの個別出典・更新日は今回確定していません。社内資料の利用有無や内部APIは確認していません。

今後は利用条件を確認した公式の農地属性と形状、地域ごとの規制・担当窓口を段階的に追加し、同じ敷地全体で照合する機能を検討します。今回の機能は取得していない条件を「なし」と埋めるものではありません。公開配布・全地域対応・Mac/Safari実機確認は別途です。

## 検証と制限

Windows / Edgeのローカルプレビューで、用途地域・設置可否を先頭にした表示、初期状態で閉じた詳細、合成メモの入力とJSON保存、パネルの開閉、発電量画面との往復後の確認日・窓口・回答・状態の保持を確認しました。「回答記録済み」にしても用途地域と設置可否は未確認のままです。保存JSON内の確認日・回答も照合しました。

狭い画面はviewport指定375×812（EdgeのDOM報告幅417 CSS px）で確認しました。ページと確認パネルに横方向のはみ出しはなく、入力欄は16px、単行欄は高さ44px以上でした。実機タッチ・Mac/Safariは未確認です。

実ブラウザーのJSON復元は、ChatGPT拡張機能の「Allow access to file URLs」が無効でファイル選択APIに拒否されました。設定は変更せず、復元・反映前確認・異なる地点の拒否のUI通し検証は未完了です。専用JSONの往復、地点違い、形式・容量・日付・状態、余分なURLの除外、文字列のテキスト表示はコード試験で確認しています。

このローカル確認では地図・住所・標高・一部ハザードの取得に失敗しました。画面は未確認・資料なしを保持しており、データ取得成功や現地条件の不存在を検証したものではありません。実案件の所在地や個人資料は試験・公開コミットに含めていません。全テスト、build、CSP、静的資産検査を実行し、結果はPRに記録します。

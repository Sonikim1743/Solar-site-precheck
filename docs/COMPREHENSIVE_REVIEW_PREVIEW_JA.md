# 総合チェック試用版

## 目的と今回の範囲

地図で範囲を指定し、3D地形分析を中心に確認する試用版。事業の検討が進んだ土地について日影・積雪・規制の見落としや未確認事項を拾う補足確認も用意する。必要な項目へ直接進める構成とし、順番を強制しない。候補地探しにも既存の地図を使える。

後から示された方針を反映し、参考発電量の数値や系統の一般説明を総合チェックへ追加する案は取り下げた。既存の発電量計算・比較・公表設備資料・保存済みメモは削除していない。接続可否の確認を要求する固定案内は、画面・レポート・活用例・新規生成メモから除いた。旧記録に利用者が書いた文章は変更しない。

## 主な変更

- 画面の主題を3D地形分析とし、地図の次に「範囲を3Dで見る」を配置。この入口では分析後に3Dを先に表示し、等高線にも切り替えられる。狭い画面では地形図を操作部より先に表示。既存の未使用 `CandidateWorkflow` を、地形・地平線・NEDO積雪・規制の4項目を示す補足確認へ変更。3Dより後ろで初期状態は閉じ、取得済みと条件解消を同一視しない。
- 規制は既存の地点照合を再利用。別の地点の結果、資料不足、未提供、取得失敗を「問題なし」にしない。敷地全体・現行指定・許認可が確認済みとは表示しない。
- 上部に追加した保存バーは取り下げ、保存・再開はツールとレポート内へ置く。新しい記録形式やデータ連携は作らない。保存済みの記録・復元機能は維持。
- 地図の作図・表示設定を地図外の操作列へ移動。主要操作と拡大縮小を44px以上にする。通常のデスクトップのホイールはページスクロール、明示的にONにすると地図拡大。狭い画面の地図操作切替は維持。
- 初期HTMLと地図画像の読込状態・画像取得失敗を表示。住所検索が1候補ならその地点を選択し、複数候補なら選択肢を残す。
- 地平線は地形のみの最大角と、既存の樹高仮定込みの入力角を区別。既存の樹高設定と手動編集を維持し、手動編集・欠測を表示。数式や既定20mを変更していない。
- 地図画面を画面切替で破棄せず非表示にし、表示設定と地点照合結果を往復で維持。計算中の既存発電量リクエストの取消処理は従来のまま。

## 発電量を再検討する際の論点

以下は現在の実装を読んだ事実であり、発電量の精度を検証した結果ではない。

`shared/generation.js` は座標、手入力DC容量、傾斜、方位、損失をPVGIS 5.3のPVcalcへ渡す。指定はERA5、結晶シリコン、架台設置、PVGIS標準地平線。初期画面の50kWp・20度・南向き・損失14%は仮条件であり、検討範囲の配置や実際の設備仕様から自動導出したものではない。年間・月別値を応答から読み出している。

既存の地形比較は `terrainAngle` で標準地平線を置換する。20mを加えた入力角は使用しない。積雪の比較は月別出現率と利用者の影響係数を掛けた仮定であり、パネルの積雪損失を実測したものではない。今回、この計算は変更しない。

次に決めるべきことは、単一の年間値を増やすことではなく、実際の配置・設備条件と詳細設計で得た基準値に対し、このアプリがどの見落としを指摘し、どの条件差を検証する役割を持つかである。配置や実績・詳細設計との照合がない現状の数字を、新しい総合結果として強調しない。

## 使い方と分離

同じPCの試用URLは `http://127.0.0.1:5187/`。停止後はリポジトリ直下の `RUN_COMPREHENSIVE_PREVIEW.cmd` で起動する。ビルド済みdistとNodeが必要。開発用の5186、運用サイト、従来のローカル版とは別のオリジンであり、保存内容は共有しない。

127.0.0.1は他のPCやスマートフォンから到達するURLではない。外部公開URLは作成していない。運用配布、mainへのマージ、PR #8のマージ・状態変更は行わない。

PR #8は規制の相談・メモの別作業。今回もApp、MapPanel、RegulatoryPointInspectorが重なる。PointInspectionSummaryとその判定集約は変更せず、既存の区域説明で使う。PR #8と同時に採用する場合は統合確認が必要。

## 検証と残る事項

Windows / Node 24.22.1 / pnpm 11.25.0で全679件、ビルド、CSP、同梱資産、リリースメタデータ検査が通過。最終コミットのCI結果はPRで別途確認する。

Windows / EdgeのCSS幅1024pxと375pxを実測し、横方向のはみ出しなし。主要地図操作は44px以上。住所候補の選択、既存計算画面との往復、範囲の保持、DEM取得、3Dの初期表示・回転、狭い画面の地形図先行表示、補足チェックの初期閉鎖、上部保存バーがないことを確認した。保存データの既存パーサーでの読込と、旧利用者メモの維持も確認。実ブラウザーでの記録ファイル選択・復元は未実施。

ブラウザー試験の範囲は公開地図上に作図した操作用図形であり、案件の候補地評価ではない。3Dの表示と回転を確認したもので、実測に対する標高・勾配・設計の精度検証ではない。Mac/Safari・実機タッチは対象外。

DEMの未提供タイルに対する404は今回の改修対象外。存在範囲の事前判定や期限付き負キャッシュは別に検証する。失敗ログを一括で消していない。既存の大きいJSチャンクのビルド警告も残る。ページ全体のアクセシビリティ適合を認定する変更ではない。

今回の画面確認は、ハザードの網羅性・法的区域の正しさ・実際の発電量精度・PDF全体・地番原本の読込・3D設計精度の検証を意味しない。個別案件・実務資料・画面画像・試験用記録は公開コミットに含めない。

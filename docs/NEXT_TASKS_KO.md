# 다음 과제 — 2026-09-24

v1.27.1의 GitHub·공개 Pages·Windows 실행판 갱신은 완료했으며 DEPLOYED_VERSION.md에 근거가 있다. 아래는 **v1.27.2 예정 작업**으로, 아직 구현·검증·배포 완료를 뜻하지 않는다.

## 지금 먼저 마칠 일 — v1.27.2
1. **단면과 지점 표시:** 단면 버튼을 추가 열기 동작 없이 항상 보이게 한다. 지점·표고·복사 항목의 간격을 정리한다.
2. **발전량만 별도 화면:** 초기 메인의 발전량 패널을 빼고 상단 메뉴에서 여는 별도 화면으로 옮긴다. v1.27.1의 같은 페이지 원칙에서 발전량만 예외로 두며 다른 기능까지 분리하지 않는다.
3. **기존 메인 유지:** 지평선·적설·필지 검토·레포트·자료·SolarPro 매뉴얼은 메인의 접이식 구성을 유지한다. 메뉴에서 핵심 기능을 이름으로 바로 찾을 수 있게 하고 GEONEX 삭제도 유지한다.
4. **변경 동작 확인:** 발전량 화면 왕복에서 지점·입력·비교조건·결과가 보존되고 레포트에도 연결되는지 확인한다. 단면 버튼 접근과 좁은 화면의 간격도 확인하여 실제 검증한 범위만 기록한다. 미변경 계산·기록 검증·기하 기능은 기존 자동 테스트 근거를 유지한다.
5. **검증 후 릴리스:** 필수 검사·빌드·배포 묶음 결과를 남긴다. 소스 커밋, GitHub 반영, 공개 배포, Windows 갱신을 각각 확인한 뒤 v1.27.2 완료 상태를 기록한다.

## 이후의 운영
- **Mac 개발 인수:** MAC_OPENCLAW_START_KO.md에 따라 최신 코드·의존성·테스트·화면과 실제 작업 폴더를 확인한다. 코드 수정은 Mac 중심, Windows는 실행판 확인과 SolarPro/CAD 업무에 사용한다.
- **배포 재현성:** GitHub CI와 Cloudflare 배포 절차를 확인한다. GitHub 갱신을 공개 배포 완료로 취급하지 않는다.
- **비공개 자료 공유:** 회사 자료에 맞는 저장 위치를 정하고 후보지 ID·수정자·원자료·최종 확인일을 기록한다. 코드와 후보지 JSON·도면·등기 자료의 동기화를 구분한다.
- **수익화 검증:** 실제 업무 시간·확인 근거·인수인계의 편리함을 평가한다. 면적만으로 설비용량을 정하거나 접속 가능·발전 수익을 보장하지 않는다.

## 새 기능의 판단 기준
**메인 흐름 유지·발전량만 별도 / 단면 버튼 바로 표시 / 짧은 제목과 요약 / 상세 기본 접힘 / 핵심 기능을 숨기지 않음 / 지점·입력 보존.**
이번 명시 요청의 발전량 예외를 다른 기능의 화면 분리로 확대하지 않는다. 기능 수나 상시 정보량을 늘리는 것을 개선으로 보지 않는다. GEONEX 재도입·API 연동은 현재 과제에서 제외한다.

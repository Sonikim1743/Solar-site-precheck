# 選択地点の区域確認

基本表示は「この地点に重なる区域」の文化財・農業地域・土砂・洪水カード。短い状態と次の確認先を示し、出典・基準日・原属性は「出典・基準日・詳しい内容」にまとめて折りたたむ。未検出、資料なし、未確認、取得エラーを分ける。農用地区域を表示した場合は農業地域とは別のカードで扱う。

地図の「検討区域」をONにすると、地図内の右端から選択地点の説明が開き、現在選択した地点の収録参考図形を照合する。隣の小さな矢印は表示ON/OFFを変えずに説明だけを開閉する。ページと地図の高さは変えず、説明内部だけをスクロールする。開いたら閉じるボタンへフォーカスを移し、「閉じる」やEscapeでも区域表示と入力を保持し、矢印へフォーカスを戻す。位置未選択では選択方法だけを案内する。PageUp/PageDownはパネル内部だけをスクロールする。検索欄の未確定文字列や、移動した地図中心は対象にしない。地図の既存クリック・筆選択・距離・作図・配置のイベントは追加・置換しない。作図中は地点照合を実行しない。

「ONの資料」は設定の一覧、結果は地点の実際の重なりである。文化財・農業地域のPolygon/MultiPolygonについて外周・穴・境界を照合し、同一原本の分割部品をまとめ、異なる原本の重なりは全件を表示する。農業地域と農用地区域は分ける。古い農用地区域は既存の追加表示設定に従い既定OFF。現行指定・資料未収録は別に確認する。

岡山・広島・山口の洪水・土砂は保存原本の面と選択地点を照合する。N03行政境界の県判定、原属性・原資料日・取得日・加工と出典を表示し、線から面を補わない。保存対象外の洪水・土砂はGSIのz17 PNGの選択地点画素を読む。着色画素の存在は「表示あり・種別要確認」とし、深さ・警戒ランク・指定名を色から推定しない。透明NoData、白色の意味未確認、404、通信・判読失敗、対象県未確認、個別条件未確認地域を区別する。土砂の県は選択地点から別途照会し、地図中心の県を流用しない。県照会失敗でも洪水・収録ベクトルの結果は残す。

説明を開いたときに照合し、同じ地点・設定で閉じて再度開く場合は完了済み結果を保持する。「再確認」で明示的に更新でき、「中止」は未確認のまま停止する。地点・ON/OFF・古い農用地区域の設定変更で旧結果を破棄し、中止・変更前の非同期結果を復活させない。透明・未提供・重なり未検出は安全や規制なしの判定ではない。地点の結果は敷地全体の判定ではなく、重なりだけで開発不可と決めない。

出典・時点・利用条件・原本未記載の測地系を表示する。岡山文化財は固定ハッシュの公開原本から名称・区分・時代に加え、詳細区分・残存記載・概要・主な出土・備考を取り込む。原本時点の記載と現況を区別し、全属性を収録したものとはしない。行政での現行確認が必要である。個別候補地の座標・検証記録は公開ソースや配布物へ含めない。

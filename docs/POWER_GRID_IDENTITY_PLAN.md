# 電力設備の実名・位置照合計画

調査日：2026-09-09。TerraLayer と同じデータの取得は未達成。

## データを分離する

- 地理：線の形状、変電所の座標、地理データID、位置の出典。
- 公式設備：電力会社、地域、設備番号、正式名称、電圧、空容量、資料更新日。
- 対応表：地理データIDと公式設備番号、確認根拠URL、確認日、確認方法。

公開CSVの設備名だけでは地理形状との対応は確定しない。最寄り・同一地名・電圧だけによる自動命名は禁止。

## 実装済み

専用地図では全取得設備を公式DBの設備番号で照合する。一意に一致し既知電圧に矛盾がない場合だけ公式名を表示。曖昧・番号なしは変更しない。変電所も対象。照合根拠を詳細欄に表示する。

## 次のデータ整備

1. 実際の比較地点を固定し、名称不明の地理IDを記録する。
2. 中国電力NWの設備一覧・系統図で正式名称と設備番号を確認する。
3. 利用許諾のある名前付き地理データ、現地設備標識などで形状・位置を照合する。
4. 根拠が揃った組合せだけ対応表に登録する。線の分割・更新時は再確認する。
5. 同じ候補地点で設備名、電圧、形状、変電所位置、距離算出方法を比較する。

## 調査先と採否

- 中国電力NW：https://www.energia.co.jp/nw/service/retailer/keitou/access/ — 公式名称・設備番号・空容量の基準。ページ上の更新表示は2026年8月28日。現在同梱DBの更新とは別。
- REPOS：https://repos.env.go.jp/web/data/mounted_data — 変電所・送電線レイヤ掲載あり。対象レイヤの取得経路とアプリでの再利用条件は未確認。まだ取り込まない。
- All-Japan-Grid：https://github.com/lutelute/All-Japan-Grid — OSM由来。説明では端点の変電所名から生成する線名があるため正式名称補完には採用しない。
- TerraLayer — 比較画面として利用。データ提供・エクスポートの許諾が確認できれば連携候補。契約や問い合わせ送信は未実施。

## 残る阻害要因

現在の名称不明設備について、公式番号と地理IDを結ぶ確実な資料をまだ得ていない。自動照合実装だけではその設備の名称は増えない。同等の網羅性を達成するには名前付き地理データの取得・許諾確認または検証済み対応表の整備が必要。

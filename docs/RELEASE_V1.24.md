# Solar Site Precheck v1.24 — 系統と発電量

2026-09-11

- 地図・距離順設備一覧・公式資料検索を一つの系統専用画面に統合。選択した設備の詳細を一覧と切り替えて表示。
- 名前の常時ラベルを初期オフ。範囲・送電線電圧・種別フィルター、公式系統図、設備確認メモを追加。
- 名称候補は未照合と区別。完全な設備番号が一意に一致した場合のみ公表容量を紐付け。ハイフンを削除して別設備を一致させる不具合を修正。
- 公式CSVを再取得し、山口を含む中国地方5県、送電線658件・変電所840件を収録。CSV内部の更新日は2026-07-27または2026-08-06。サイト全体の更新日とは異なる。
- 同一地点の参考年間・月別発電量をPVGIS 5.3 / ERA5で計算するAPI・画面を追加。入力条件、期間、出典と共にレポート・設備確認メモへ反映。既存Solar Proの年間発電量入力も表示。
- 計算は35秒で終了、取消可能。候補地変更・条件変更時に古い結果を再利用しない。PVGIS標準地平線を使用し、アプリ独自地平線、NEDO積雪係数、PCS・出力制御は未反映。
- 公表容量から接続可否・出力制御率を推定しない。

検証：105件の自動テスト成功、製品ビルド成功。新見市の既存確認地点で周辺12設備（送電線8・変電所4）を実際に取得。公式名検索・設備詳細をブラウザ確認。ユーザー同意後にPVGIS実計算が成功（50 kWp・南向き・20°・損失14%で年間63,694.55 kWh）。ブラウザに保存済みの別候補地の65,089 kWhが条件・12か月値と共にレポートへ反映されることも確認。取得日の日本時間表示を修正。

旧クラウド開発本の全機能を統合した版ではない。独自地平線の前後比較、スナップショット再読込、地域集客ページ、販売決済は今後の統合対象。公開サイトへの反映は未実施。

# Solar Site Precheck v1.27 변경 안내

작성일: 2026-09-24. v1.26에서 개발한 발전량 비교와 화면 개선에 v1.27 필지·검토영역 기능을 합친 갱신본입니다. 이 문서는 개발 변경 사항과 배포 준비 상태를 설명합니다.

## 현재 확인 상태

| 항목 | 상태 |
|---|---|
| 단위 테스트 | **161개 통과** — 현재 확정된 결과 |
| 브라우저 화면·지도 조작·인쇄 검증 | 진행 중. 최종 완료로 판정하지 않음 |
| 배포 패키지·실제 배포 검증 | 진행 중. 공개 사이트 또는 다른 PC에 갱신이 완료됐다는 뜻이 아님 |

공개 배포, GitHub 온라인 업데이트용 파일 게시, 각 PC의 갱신은 별도 절차입니다. 이 문서나 소스 파일을 받는 것만으로 실행 중인 앱이 바뀌지는 않습니다.

## v1.26에서 합류한 발전량·기록 화면

- 기본 PVGIS 발전량과 적설·주변 지형 조건을 선택한 시험값을 구분합니다. 적설 조건과 주변 지형 조건은 각각 선택·해제할 수 있고, 자료가 부족하면 적용을 제한합니다.
- 적설 비교는 확인된 NEDO 월별 출현율과 사용자가 입력한 영향도에 따른 가정입니다. 패널 위의 실제 적설 손실률을 측정한 결과가 아닙니다. 주변 지형 비교는 PVGIS 기본 지형을 해당 후보지의 DEM 지평선으로 대체하며, 지형 손실을 이중으로 더하지 않습니다.
- 조건 변경 시 이전 비교를 해제하고, 취소·오류가 나도 기본 발전량을 유지합니다. 후보지·설비 조건이 바뀌면 그 조건에 맞춰 다시 계산해야 합니다.
- 연간 기본값·시험값·차이를 함께 보고, 12개월 막대를 누르거나 키보드로 이동해 월별 수치를 확인합니다. 월별 기본·시험 발전량과 적용 조건을 보고서·CSV에도 구분해 남깁니다.
- 보고서의 발전량 화면은 연간 요약과 월별 발전량 표로 정리했습니다. 별도로 입력한 Solar Pro 실무 메모는 PVGIS 시험값으로 자동 교체하지 않습니다.
- 검토 기록 저장·파일 선택·확인 후 적용·직전 상태로 되돌리기를 작은 도구 모음으로 모았습니다. 기록을 열면 저장 당시 조건을 이어서 검토할 수 있습니다.

비교의 계산 범위는 [적설·주변 지형 비교 설명](GENERATION_SCENARIO_PREVIEW.md)을 참고하십시오. 해당 문서의 v1.26 시험판 표시는 개발 경위이며, 이번 합류 버전은 v1.27입니다.

## v1.27의 지도·필지 흐름

1. 기존 XML·ZIP·GeoJSON 지번 자료를 읽습니다. 지번 검색은 불러온 자료 안에서 수행합니다.
2. `対象の筆` 또는 `参考の筆` 모드에서 필지를 담습니다. 대상·참고 추가와 역할 변경만으로 계산점이나 발전량을 바꾸지 않습니다. 목록의 `この筆で計算`을 누르면 해당 필지 내부의 한 점으로 계산 위치를 바꿉니다. 실제 설비 예정 위치와 맞는지 확인해야 합니다.
3. `検討範囲`와 `除外範囲`는 지도에서 꼭짓점을 순서대로 지정하고 확정합니다. 1점 되돌리기와 취소를 지원합니다. 계산점 모드 외에 빈 지도를 누르는 동작은 후보지를 이동시키지 않습니다.
4. 대상 필지와 그린 검토영역이 모두 있으면 **둘의 공통 부분**을 검토 면적으로 사용합니다. 검토영역이 없으면 대상 필지의 합집합, 대상 필지가 없으면 그린 영역을 사용합니다. 참고 필지는 집계하지 않으며, 겹치는 부분은 중복 계산하지 않습니다. 제외영역은 검토영역 안에 겹치는 부분만 차감합니다.
5. 대상 필지 도형·검토영역·제외분·유효영역의 면적을 확인한 뒤 발전량 화면에서 설비 조건을 입력합니다. **면적에서 설비 용량이나 발전량을 자동 확정하지 않습니다.**

면적은 입력 도형에 따른 참고값입니다. 공부상 면적·확정 경계·설치 가능 면적을 보증하지 않습니다. `parcelInfo.area`는 소재지 문자열이며 면적 숫자가 아닙니다. 1개 계산점의 지형·발전량이 필지 전체를 대표하는 것도 아닙니다.

`GEONEXで確認`은 공식 사이트를 별도 탭으로 여는 보조 연결입니다. 소재지·지번이 갖춰져 있으면 해당 정보를 연결 주소에 사용하고, 부족하면 기본 사이트를 엽니다. GEONEX 내부 지도·데이터를 앱에 내장하거나 결과를 자동 취득하는 API 연동은 이번 범위에 없습니다.

## 저장·CSV·보고서

- 새 검토 기록은 **schemaVersion 2**로 저장합니다. 선택한 필지의 도형·대상/참고 역할·출처 파일명·읽은 시각, 검토영역과 제외영역을 함께 보존합니다. 원본 파일 전체를 저장하는 기능은 아닙니다.
- 기존 **schemaVersion 1** 기록도 열 수 있습니다. 과거 파일에 없던 경계는 복원할 수 없으므로 필지 검토 항목은 빈 상태로 시작합니다. 다시 저장하면 새 형식이 되며, 옛 앱에서 새 형식을 열 수 있다고 보장하지 않습니다. 원본 기록은 별도로 보관합니다.
- 재개할 때 선택 경계는 원본 지번 파일이 없어도 표시합니다. 원본 전체를 다시 검색하려면 해당 자료를 다시 읽어야 합니다. 가져오기를 적용한 직후에는 직전 상태로 한 단계 되돌릴 수 있습니다.
- 기존 후보지 CSV에 면적 요약·대상/참고 구분·소재지/지번·출처 파일명·읽은 시각을 추가합니다. CAD 좌표점이나 SIMA/DXF 도면을 내보내는 기능은 아닙니다.
- 기존 보고서에 경계 미니도, 4개 면적, 계산점, 해석 조건, 필지별 출처 목록을 추가합니다. 일반 목록은 페이지당 최대 8필지이며, 긴 지번·주소·출처는 더 적게 나눕니다. 선택 필지 없이 검토영역만 그린 경우도 보고서에 표시합니다.

저장된 결과는 저장 당시 자료입니다. 다시 연 것만으로 공식 원자료나 발전량이 최신으로 조회되지는 않습니다. PDF 원본·PDF 편집 상태, 시군구 단위 전체 지번 자료, 전체 계통 지도와 공식 DB 본체는 별도로 관리합니다.

## 다음 과제

- **Mac을 주 개발 PC로 정리:** 한 개발 브랜치에서 변경을 모으고, Windows는 실행·현장 검증 역할로 구분합니다. 같은 파일을 여러 PC에서 동시에 수정하지 않도록 작업 기록과 상대 경로를 공유합니다.
- **Mac 개발 브랜치와 CI:** 의존성 잠금 파일을 기준으로 빌드·단위 테스트·자산 검증을 자동화하고, 검증된 커밋으로 배포 파일을 만듭니다. 다른 PC는 같은 커밋과 버전을 받도록 합니다.
- **GEONEX 정식 연동 판단:** 공식 API/MCP 제공 범위, 이용 조건, 재배포·저장 권리를 확인한 뒤 구현 범위를 정합니다. 공개 화면에서 보이는 기능만으로 데이터 이용 권한을 추정하지 않습니다.
- **공식 출처의 최신성:** 공공 지번·계통 공표 자료·기상 자료의 기준일과 취득일을 구분하고, 저장 기록을 재개할 때 갱신이 필요한 항목을 더 분명히 안내합니다.

배포 파일과 실행 방법은 [배포 패키지 안내](DEPLOYMENT_PACKAGE.md)를 따릅니다. 최종 브라우저·배포 검증 결과는 배포 담당자가 별도 기록으로 확정해야 합니다.

# 配布パッケージ v1.28.0 候補 / 2026-10-08

本書はv1.28.0候補の配布準備手順です。`feat/terrain-area-v1.28` でローカル実装を進めており、まだ公開配布していません。公開・Windows実行版の既存の確認記録はv1.27.2の `docs/DEPLOYED_VERSION.md` に保管しています。本書やソースのバージョンだけで公開サイトの更新完了とは判断しません。最終検証の結果、ソースコミット、パッケージのハッシュ、配布IDは実際の確認後に別途記録します。

## v1.28.0候補の変更と記録の再開

- v1.26で開発した基本発電量と積雪・周辺地形の選択比較、月別発電量の画面・報告書、小さな検討記録ツールバーを含みます。基本値と仮定による試算は区別します。
- 筆を「対象」「参考」に分けて選択し、検討範囲・除外範囲を作図できます。対象筆と検討範囲の両方があれば共通部分を採用し、範囲内の除外分を控除します。参考筆は面積集計に含めません。面積から設備容量・発電量は自動確定しません。
- 選んだ有効範囲の実DEMを取得し、地図の等高線・勾配、平面図、3Dで同じ範囲を確認できます。対象筆と指定範囲の共通部分から除外分を引いた図形を使用します。地図上の参考図形であり、測量済みの筆界ではありません。
- 3Dは高さを強調しない1:1の地形です。表示・集計格子5mと原資料の解像度は区別します。局所勾配は東西・南北10m幅の差分による参考値で、欠測・資料の混在を表示します。造成量・設置可能容量・施工可否は未判定です。
- 「地形図面 · A3」は等高線・勾配の平面図と、同じDEMの二つの固定視点を含むA3横2ページです。「地形PDFを保存」でブラウザ内に画像形式のPDFを作成します。文字の検索・選択やCAD編集はできません。長い現地メモは抜粋と表示し、全文は既存の候補地チェックと記録に保持します。PDF作成のために図面や本文を外部へアップロードしません。DEM取得時の国土地理院への地図座標照会とは別の処理です。
- 「活用例・資料案内」で無料の出力、実務での使い方、仮条件の操作例、有料資料の企画状況を確認できます。有料資料は販売未開始です。
- 「検討記録を保存」で候補地の条件・結果・メモをJSONへ保存。「記録ファイルを選ぶ」で内容を確認して再開します。開いた直後は一段階だけ元へ戻せます。
- 設備確認メモを保存するとレポートと検討記録に追加します。同じ設備は更新、直近20件までです。以前のJSONファイルは自動更新されないため、変更後は再保存してください。
- 新しい記録はschemaVersion 3で保存し、選択筆の図形・対象/参考・出典/読込日時・検討範囲・除外範囲に加え、取得済み範囲の標高・資料・取得日時を含みます。読み込み時に同じ範囲から派生値を再計算します。従来のschemaVersion 1/2も読み込めますが、元の記録にない図形や範囲地形を復元したことにはしません。新形式を旧アプリで開けるとは限らないため、元の記録を保管してください。
- 保存対象外：PDF原本・PDF編集状態、読み込んだ地番原資料の全図形、系統の全設備地図、公式DB本体、結線アシストの機器設定。別PCへ移す場合は記録ファイルと必要な原資料をコピーします。
- CSVに範囲面積・筆の区分と出典を追加し、報告書には概略境界図とページ分割した選択筆一覧を追加します。
- 取得済み結果を再開した場合は保存時の資料です。接続可否・工事費・出力制御の確認に代わるものではありません。
- 更新を実施した後に、アプリ下部のVersionが1.28.0になっていることを確認してください。付属の従来操作PDFはv1.23です。範囲地形の仕様と限界はソース側の `docs/TERRAIN_AREA_V1_28_KO.md` を参照してください。過去のリリース文書は当時の記録です。
- 本ZIPの提供だけではGitHubのオンライン更新先や公開サイトは更新されません。


## Cloudflare版（OpenClaw向け）

最終検証後に作成した `SolarSitePrecheck_v1.28_YYYY-MM-DD_cloudflare.zip` を新しい空フォルダーに展開してください。日付は実際のビルド日です。このファイル名の記載は配布物の作成完了を意味しません。`dist` だけでなく、同階層の `functions`・`shared`・`wrangler.toml` も必要です。既存の壊れた `.git` はコピーしないでください。Windows用の `release_light.zip` と取り違えないでください。

展開先のルートで、Cloudflareに認証済みのWranglerを使用します。

```sh
npx wrangler pages deploy dist --project-name solar-site-precheck
```

ZIPをダッシュボードへドラッグする方法ではなく、Functionsを含めてWranglerで配布してください。このパッケージはビルド済みであり、`pnpm build` の再実行は不要です。配布前に現在の本番デプロイIDを控え、問題があればそのデプロイへ戻してください。既存のAccess設定・公開範囲は変更しません。

本番URLでの確認:

```sh
node work/preflight-release.mjs https://solar-site-precheck.pages.dev
```

- NEDO PDFの数値OCRが動作し、CSPエラーがないこと。
- `/manual/site-operation-guide-v1.23.pdf` がPDFとして開くこと。

## ローカル更新版

最終検証後に作成した `SolarSitePrecheck_v1.28_release_light.zip` は既存のWindowsローカル版の更新用です。Node.js本体は含みません。検討記録を保存し、起動中のローカルサーバーを停止して、既存の `dist`・`work` と起動/更新スクリプトをバックアップしてください。その後、同名フォルダーとZIPに含まれる起動/更新スクリプトを更新します。既存の `runtime/node.exe` と個人データは維持します。`RUN_PORTABLE.cmd` で再起動し、Version 1.28.0と保存記録の読み込みを確認します。MacでWindowsの `.cmd` や `node.exe` を実行する手順ではありません。

## 継続して搭載する機能と検索の読み方

- 電力データを同一オリジンのAPIから取得。上流障害への切替・キャッシュ・利用制限時の停止を実装。
- OCR worker / WebAssembly / 英語モデルを同梱。CDNの許可設定に依存しません。
- 操作マニュアルPDFを同梱。存在しない資料URLは404にします。
- 5→10→20→50kmの順に、公開地図に66kVまたは77kVと記載された最寄り候補を探索。見つかった時点で停止し、変電所は取得範囲内の参考情報として表示。
- 50km上限・通信障害・利用制限では停止します。取得済み結果は残します。電圧未登録は66・77kVと推測せず、参考系統線として区別します。
- 距離は公開線形への概算直線距離で、引込経路や接続先の確定値ではありません。公開データの欠落があるため、全国の絶対的な最近接を保証しません。線が見つかっても接続可否・空容量が確定したことにはなりません。

`release-manifest.json` にビルド対象、ソースコミット、各ファイルのSHA-256を記録しています。このZIPには認証情報・`.git`・社内用`.spt`テンプレートは含めません。

Wrangler設定の形式: [Cloudflare公式ドキュメント](https://developers.cloudflare.com/pages/functions/wrangler-configuration/)

範囲作図は地図上の「範囲を描く」「除外」の2ボタンから開始します。同じボタンを再度押すと作図を終了。3点以上では開始点の再クリック、または下の「確定」で完成します。ファイル・地番・面積・管理は地図下の「範囲・地番の詳細」で開きます。画面3Dはドラッグと矢印キーで回転でき、報告書の視点は固定です。

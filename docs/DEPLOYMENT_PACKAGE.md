## 今回の使い方と変更

参考配置は横置き720Wの **4段固定 × 4〜8列**。モジュール傾斜15°・アレイ間前後の空き3.3mが初期値です。地形勾配10°未満を初期条件に、15°・20°未満も比較します。配置方位・上下傾斜・地形勾配は独立です。「真南固定・最大配置を比較」で南180°の開始位置を最大32案・8秒の範囲で比較し、明示的に適用します。手入力と前回の結果は取消・失敗・条件変更だけでは置換しません。図の下で架台を増減し、青い架台を個別除外、点線から復元します。DCは枚数×720W、ACは約の範囲として表示します。

仮フェンスは現在選択中の架台の平面外形を一つの凸包にまとめ、端の空きと同じ実距離をメートル単位で外側に取り、有効範囲で切り取る高さ1.2mの参考表示です。除外した架台を囲いの計算から外し、配置が空ならフェンスも作りません。欠測をつながず、測量境界・施工線を示しません。

地図の「地番選択」から表示境界をプレビューし、「選択完了 → 3D」で同じ合併形状を3D・シンプル一括解析へ渡します。PMTilesの表示断片だけを必要な隣接タイルから結合する参考領域で、原本全筆・測量境界の保証はありません。穴・凹形・分離領域を保持します。密集地番は引出線・未配置一覧を使い、単独配置図の地番線とラベルは有効範囲内に限定します。上部「ツール → 系統確認」の電柱・鉄塔は公開OSMを独立して取得します。

地図で範囲・除外を描き、同じ有効範囲の等高線・勾配・3D・レポートを確認します。範囲の開始点を再クリック、または下部の「確定」で作図を完成できます。公開地番は「地番」ON/OFFで参考筆界と番号を重ねます。地名は初期状態で表示。通常はズーム19、範囲・除外の作図中だけ21まで拡大します。確定・取消後は19へ戻り、中心・作図結果を保持します。「範囲・地番の詳細」は上部「ツール」から開きます。

- 範囲レポートに背景地図、位置・面積、地形結果と次の確認事項を表示します。
- 3Dは側面・底面を持ち、中心を固定して回転・見下ろし・拡大を操作します。高さ2倍は表示だけの強調で、数量・実勾配を変えません。配置図はA3横1枚に同じ北上・縮尺・範囲の2図を表示。左はモジュール、右は実DEM等高線・勾配・地番です。別地形報告書は比較と最後の注記を含む4ページです。
- 勾配割合は各5mセルと有効範囲の投影面積の交差から集計します。穴・除外・NoDataを区別し、四色と未確認で100%とします。境界外最低10mの周辺地図は配置・統計へ追加しません。標高取得日は元の測量日ではありません。
- 地点の表示・コピーは北緯・東経の度分です。内部の正確な座標は保持します。
- 発電量と系統確認は上部メニューから開きます。地平線・積雪・レポート・資料・Solar Proガイドは主画面の折りたたみ構成を維持します。

範囲と公開筆界は概略検討用です。表示境界を計算対象に使う際にはプレビューと「選択完了」が必要です。施工可否、所有権、接続可否や収益は別に確認します。3Dの側面は地層・造成量を表しません。

## Cloudflareへ公開

Cloudflare ZIPを新しい空フォルダーへ展開し、`dist`・`functions`・`shared`・`wrangler.toml` が同階層にあるルートで実行します。ビルド済みのため再ビルドは不要です。認証済みWranglerを使います。

```sh
pnpm dlx wrangler@4 pages deploy dist --project-name solar-site-precheck --branch main
```

Functionsも必要なため、distだけのアップロードでは不十分です。事前に現在の本番デプロイIDを記録し、不具合時にはその版へ戻せるようにします。GitHubへのpushだけではこのPagesプロジェクトは更新されません。公開範囲や認証設定の変更は、この更新手順に含みません。

公開後は版・日付・実行対象とmanifestの公開ファイルハッシュ、実応答のCSPを確認し、次のHTTP確認を行います。

```sh
node work/preflight-release.mjs https://solar-site-precheck.pages.dev
```

- NEDO API、異常メッシュ、PDF APIのGET制御、マニュアルPDFのContent-TypeとPDFシグネチャ、欠落PDFの404を確認。
- 実画面で地域名・地番表示、範囲・除外、作図中の拡大、地形/3D、背景地図付き範囲レポートを確認。
- 新しい画面に再読み込みし、参考配置のWorker計算、勾配比較、個別除外・復元、仮フェンス、図下の増減、「?」の開閉と中止・エラー時の操作を確認。公開OSMの電柱・鉄塔は既存系統情報と分けて確認。
- 上部メニューから発電量・系統へ往復して候補地が維持されること、狭い画面で横にはみ出さないことを確認。

HTTPの成功だけで画面・OCR・PDF出力の全操作を確認したことにはしません。実際に確認した環境と未確認項目は公開記録に分けて残します。

## Windowsローカル版を更新

Windows ZIPは既存環境への更新用で、Node.js本体を含みません。

1. 検討記録をJSONへ保存し、ローカルサーバーを終了します。
2. 既存dist・work・起動/更新スクリプトをバックアップします。
3. ZIP内の同名フォルダーとスクリプトを更新します。既存 `runtime/node.exe` と個人データは保持します。
4. `RUN_PORTABLE.cmd` で起動し、ブラウザーを再読み込みしてVersion 1.28.2と保存記録の読み込みを確認します。

オンライン更新は公開GitHub mainのZIPとメタデータを読みます。ZIPの受け取りだけで他PCが更新されたことにはなりません。MacでWindowsの `.cmd` や `node.exe` を実行する手順ではありません。

## 記録の保存と引継ぎ

schema 3は選択筆、対象/参考、範囲・除外、取得済み範囲標高・出典・取得日時を保存し、再開時に派生値を計算します。schema 1/2も読込可能ですが、元の記録にない図形や地形を復元したとは扱いません。新記録を旧アプリで開けるとは限らないため、元ファイルを保管します。

保存対象外はPDF原本・PDF編集状態、読み込んだ地番原資料の全図形、系統の全設備地図、公式DB本体、結線アシストの機器設定です。設備メモを変更した場合もJSONを再保存します。別PCへ渡す際は必要な原資料を別に渡します。

参考配置の条件・結果・個別除外・仮フェンスはJSON記録へ保存していないため、再読み込み後は再計算します。現在の適用結果は配置図PDFと地形報告書へ出力できます。PDFは画像形式で、文字検索・選択・CAD編集には使えません。参考容量は施工確定値ではありません。

Mac/Safari実機、複数タブの保存衝突、異なる実行環境でのgeometry key一致は未確認または未解決です。本リリースでこれらが解消したとは扱いません。付属の従来操作PDFはv1.23で、最新地形機能の操作書ではありません。ソース側のREADME・更新案内と `docs/TERRAIN_AREA_V1_28_KO.md` が現行の説明です。

この配布物には認証情報、.git、個別案件の記録・PDF・CAD・社内用.sptを含めません。

# v1.27.1 — 한 페이지 작업 흐름과 접이식 구성 정리

상태: **2026-09-24 GitHub·Cloudflare·Windows 5173 갱신 완료**. 실제 커밋·배포·검사 결과와 한계는 `DEPLOYED_VERSION.md`를 따른다.

## 최신 사용자 결정
사용자가 중요하게 본 것은 첫 페이지에서 핵심 작업을 끝내는 흐름과 기존 레포트·자료·SolarPro의 접이식 구조다. 과도한 정보량을 줄이라는 요구를 화면별 분리로 해석했던 중간안은 철회한다. 기능을 찾기 어렵게 숨기는 것으로 간결함을 대신하지 않는다.

## 이번 최종 변경 범위
- 지도에서 시작해 필요한 검토와 레포트·SolarPro 준비까지 같은 페이지에서 이어간다.
- 기존 접이식 구성을 유지하고, 발전량·필지 검토도 필요할 때 여는 accordion으로 제공한다.
- 짧은 섹션 제목과 요약을 쓰고 상세 조건·설명은 기본 접힘으로 둔다. 발전량 작업을 열면 연간 핵심값·월별 그래프를 먼저 보여주고 계산에 필요한 입력을 사용할 수 있다.
- 도구 메뉴를 한 번 열면 「地平線・日影を計算」「積雪データを見る」「レポート」가 이름으로 보인다. 선택하면 같은 페이지의 해당 영역과 접힌 항목까지 연다.
- 섹션 열기/닫기와 메뉴 이동에서 위치·입력·검토 필지·기존 결과를 보존한다.
- GEONEX 확인 탭·버튼·외부 확인 링크 삭제는 유지한다.

발전량 API·수식, 적설/지형 비교, 필지 면적 계산, 검토 기록 저장·복원, 보고서 기능은 유지한다.

## 제품 확인 기준과 후속 실사용 확인
1. 다른 작업 화면으로 옮길 필요 없이 한 페이지에서 핵심 작업을 이어 끝낼 수 있다.
2. 기본 접힘 상태에서 제목과 짧은 요약으로 필요한 기능을 찾고, 열었을 때 필수 입력과 결과를 사용할 수 있다.
3. 지평선·적설·레포트 메뉴가 직접 연결되고 기존 위치·입력·결과를 지우지 않는다.
4. 대상/참고·경계·제외·내부점 선택, 발전량 계산·비교, 저장/재열기·레포트를 실제 화면에서 확인한다.
5. 모바일에서 같은 페이지의 접이식 구성을 확인한다. 화면 분리안의 비교 입력 왕복 시험은 제외하고 컴포넌트 상태 보존 보강은 유지한다.
6. 필수 검사·빌드·배포 묶음을 확인하고, 실제 공개 후 버전·배포 ID·소스 커밋을 별도로 기록한다.

미변경 수식·기록 형식·기하 처리는 자동 테스트 증거를 유지한다. 모바일 등 아직 확인하지 않은 항목은 완료로 표시하지 않는다.

최종 브라우저 상태는 V1_27_1_BROWSER_CHECK_KO.md를 따른다. 이전 화면 분리 중간안의 검사 결과는 이번 최종 QA 완료로 사용하지 않는다.

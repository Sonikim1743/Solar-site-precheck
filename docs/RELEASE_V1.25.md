# v1.25 — 2026-09-11

候補地の検討記録をJSONへ保存し、内容確認後に再開できます。条件・PVGIS月別結果・メモ・地平線・地形断面・確認済み積雪・保存した設備メモを含みます。PDF原本、地番の全図形、系統の全設備地図、公式DB本体は含めません。

ファイルは2MBまで。形式・版・数値・座標・月別値・条件の一致を検証し、不正な記録では現在の作業を変更しません。復元時の遅い取得結果を破棄し、直前の候補地を一段階だけメモリから戻せます。保存時の資料は未再照合と画面・PDFに表示します。標高がない記録は候補地を変えずに標高を取得できます。

設備確認メモはレポートと検討記録へ追加（同一設備は上書き、直近20件）。ブラウザへの仮保存は残りますが、別PCへ移す場合・確実に残す場合はJSONファイルを保存してください。記録再開は候補地検討機能が対象で、別画面のPDF編集状態や結線アシストの機器設定は含めません。

活用例・資料案内に無料出力の使い道、保存場所、仮条件の練習例、結果を読む条件、有料資料の企画状況を追加。テンプレート選択はファイル名確認に限ること、結線の機器容量は発電量に自動反映しないことを明示。既存操作PDFはv1.23と表示。価格・提供範囲・利用条件などは販売前に決定します。

検証：118件の自動テスト、実際の候補地記録の保存・読み込み・復元・取り消し・戻し、練習例の確認。候補地と発電量を維持しました。公開サイトへの配信は未実施。

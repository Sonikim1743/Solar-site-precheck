# シンプル画面プロトタイプ

URL: http://127.0.0.1:5186/?design=simple&prototype=1

起動: リポジトリ直下の `RUN_SIMPLE_PROTOTYPE.cmd`。Node.js とインストール済みの依存パッケージが必要です。ポート5186が既に起動している場合はURLを直接開いてください。

`design=simple` で新しい画面を表示し、上部の比較ボタンで従来画面に戻れます。通常URLは従来画面のままです。画面切替は同じアプリ内で行うため選択地点と分析状態を引き継ぎます。詳細欄の開閉状態は切替時にリセットされる場合があります。

## 変更内容

- 検索・地図を中心とした白地の画面。見出し、余白、枠線、強調色を整理。
- PDF、登記、マニュアル、外部リンク、初期化を「業務ツール」に集約。
- 地平線・NEDO・入力欄を初期状態で折りたたみ。
- 手順リンクから分析欄・レポートを直接展開。
- 地図・標高・断面・座標コピー・系統検索は既存の実機能を利用。
- 新しい画面スタイルは画面表示だけに限定し、印刷用CSSには適用しない。

## 第2案：基本調査と試験機能の整理

- 選択地点の住所・座標・標高・コピー・Googleマップへのリンクを一つの領域に整理。
- 地形断面、地平線・日影、NEDO積雪の3項目に実際の取得状態を表示。取得数はデータ取得状況であり、候補地の適性評価ではありません。
- 地平線・積雪のカードから詳細欄を開いて該当する入力位置へ移動。
- 電力確認は報告書の下の任意の試験機能へ移動。基本3項目の取得数には含めません。既存の電力検索・レポート掲載条件は維持。
- デスクトップ3列、390pxでは1列のカード配置を実ブラウザで確認。NEDO詳細への移動、電力パネル初期折りたたみ、DOM上のレポート→電力の順序を確認。
- 再ビルドとアプリシェル・レポートの回帰テスト4件成功。確認時のブラウザエラーログなし。

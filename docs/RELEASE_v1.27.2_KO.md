# v1.27.2 구현 당시 기록

2026-09-24에 배포·검증을 완료했다. 최신 일본어 변경 기록은 [RELEASE_v1.27.2_JA.md](RELEASE_v1.27.2_JA.md), 배포 증거는 [DEPLOYED_VERSION.md](DEPLOYED_VERSION.md)를 따른다. 아래는 구현 당시 정의한 범위다.

## 최신 명시 요청

- 단면 버튼은 추가로 펼치는 동작 없이 항상 보이게 한다.
- 단면에 양 끝 평균각·경사율·수평 10m당 높이 변화를 구분하여 표시한다. 가장 급한 구간은 실제 수평 거리를 쓰고, 결측 구간은 이어 그리지 않는다. 그래프의 눈에 보이는 기울기는 실제 각도와 다르다는 안내를 유지한다.
- 지점·표고·복사 항목의 간격을 정리하여 정보와 조작을 구분한다.
- 발전량만 초기 메인에서 빼고 상단 메뉴로 여는 별도 화면에 둔다.
- 기존 지평선·적설·필지 검토·레포트·자료·SolarPro 매뉴얼은 메인의 접이식 구성을 유지한다. GEONEX 삭제도 유지한다.

발전량 분리는 v1.27.1의 같은 페이지 원칙에 대한 이번 요청의 예외다. 다른 기능까지 별도 화면으로 옮기거나 핵심 메뉴를 숨기라는 뜻이 아니다. 계산 기능을 없애는 변경도 아니다.

## 확인할 범위

1. 단면 버튼이 바로 보이고, 지점·표고·복사 간격과 조작이 맞는지 확인한다.
2. 초기 메인에는 발전량 패널이 없고 상단 메뉴로 해당 화면을 열 수 있는지 확인한다.
3. 메인과 발전량 화면 왕복에서 지점·입력·비교조건·결과를 보존하고 레포트 연결을 유지하는지 확인한다.
4. 기존 메인의 접이식 기능을 유지하며 실제 확인한 화면 크기와 미확인 범위를 기록한다. 미변경 계산·기록 검증·기하 기능은 기존 자동 테스트 근거를 유지한다.
5. 필수 검사·빌드·배포 묶음을 확인한 뒤 소스 커밋, GitHub 반영, 공개 배포, Windows 실행판 갱신을 각각 기록한다.

# 電力設備詳細の改善

## 実装

- 従来画面に設備名・設備番号・県名による公式DB検索を追加。
- 広島・岡山・島根・鳥取のDBをまとめて読み込み、県境の照会に対応。
- CSVの負号が消える不具合を修正。正方向と符号から算出した予想潮流方向を区別。
- 設備容量・運用容量・制約要因・出力制御対象を追加。未記載と0を区別。
- 公表の端点名が完全一致する変電所・他送電線を参照可能。潮流方向から系統上位・下位は断定しない。
- 地図でDB照合できた送電線に詳細ポップアップを追加。
- 単一のOSM電力関係に属する線の欠落タグを補完。複数回線の共用線には任意の名前を付けない。
- relation形式の変電所に対応。電圧が矛盾するDB照合を除外。
- 電力DBをサービスワーカーの古いキャッシュから返さないよう変更。

## 検証と限界

- 公式ZIPを再取得・再生成。CSV内部の更新日は2026年8月6日（取得日やWebページ全体の更新日とは区別）。
- 東城線 広④L104: 66kV、設備容量47MW、運用容量47MW、予想潮流-24MW。正方向は東城→帝釈川、予想潮流は逆向き。空容量は未記載。
- 34.902587, 133.319231の5km実API照会はHTTP200。名称未記載の線3件、変電所0件。地図情報の欠落は残る。
- 公式DBには座標がなく、検索した設備を最寄り設備として自動配置しない。TerraLayerの独自データを転載していない。
- 本番デプロイ未実施。従来UIのローカル確認用ビルドで検証。

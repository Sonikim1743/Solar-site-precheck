## 実Appで再現した不一致

先の六組検証はSimpleReviewPanel単体の合成であり、App内の二つの出力経路を検証していませんでした。今回、実際のAppをマウントし、通常のdraft読込と画面ボタンだけで以下を再現しました。外部取得だけを合成データへ置換し、配置Worker・React状態・PDF生成は実装本体を使用しています。

| 操作 | 詳細／3枚レポート | シンプル1枚 |
|---|---|---|
| 10°を双方で計算（修正前） | 10° / 480枚 / DC345.60kW | 10° / 644枚 / DC463.68kW |
| 詳細を20°へ再計算してシンプル出力（修正前） | 20° / 448枚 / DC322.56kW | **10° / 644枚 / DC463.68kW** |
| 詳細10°の後シンプル20°を計算し3枚レポート出力（修正前） | **10° / 480枚 / DC345.60kW** | 20° / 644枚 / DC463.68kW |

原因はAppの `terrainPreview` と `simpleWorkflow` に入力・適用済み配置が分かれ、3枚レポートは前者だけ、シンプルは後者だけを読んでいたことです。同じ角度でも詳細の方位固定とシンプルの開始位置探索を別計算していたため枚数も変わりました。PDFの文字だけの問題ではなく、モジュール角の実座標でも10°のままでした。

## 修正

- Appの配置入力と計算方式を共通の元にし、詳細の入力をシンプルの閉じた要約・選択値にも反映。
- 同じ範囲・DEM取得・適用条件の完成済み配置があるときは、その架台プールと個別除外・数量・フェンスをシンプル出力でも使用。別の探索で勝手に枚数を変えません。
- シンプルで新しく計算した場合は、完成済みの実配置と同じ取得済みDEMをAppへ反映し、地形パネル・3枚レポート・1枚配置図が同じモジュール座標を使います。配置計算エンジンとWorker本体は変更していません。Worker配布物のSHA-256も公開版と同じ `23b835d701bbfee2c36ba5cb05d731d8ec47bcdc2a785ec63203e57d64e13eb1` です。
- 手動入力した方位・任意のパネル角は維持。シンプルの真南・最適を明示選択した場合だけ基準方位180°へ切替。手動値を持つ場合だけ選択欄に「入力方位を維持」を表示。
- 入力・計算方式・地形取得が適用結果と異なる、または計算中のときは旧配置のPDFをブロック。Appボタン、レポート表示、PDFモデル生成の各入口で検査。詳細Workerも現在の入力キーを確認し、遅延応答を破棄。
- 範囲が異なる結果を別のDEMへ貼り付けません。シンプルの選択筆合計と詳細の切り取り範囲が異なる場合は、その別範囲の3枚出力をブロックし、既存の範囲・入力を保全します。

## 検証

実App回帰：`tests/optional/appLayoutOutputWorkflow.test.mjs`。テスト用の状態・出力読み取り計測以外はApp本体のコードを使い、実Worker・実Canvas/PDFで交差検証しました。テスト用の新規一時プロファイルだけを使用し、実利用者のlocalStorageや選択データは読まず変更していません。

- 詳細10→20→シンプル1枚：双方 **20° / 448枚 / DC322.56kW**。
- シンプル20→3枚レポート：双方 **20° / 448枚 / DC322.56kW**。実モジュール角19.999999999999766°。
- 方位135°：双方492枚・DC354.24kW。1架台除外とフェンスを保持して双方464枚・DC334.08kW。シンプル保存時に配置Workerを再実行しないことも確認。
- 真南固定：双方180°・644枚・DC463.68kW。同じ `south-fixed` 結果を使用。
- 最適（参考）：双方157.5°・564枚・DC406.08kW。同じ `optimized` 結果を使用。
- 各出力の全架台・全モジュール座標配列を比較し一致。単体回帰では各モジュールの隣接辺から傾斜を再計算して20°と照合。
- 未適用の角度変更で旧保存リンクを非表示にし、既存の1枚／3枚出力を無効化。実Workerの10°応答を保留し、入力を20°へ変えてから応答を解放しても20°を上書きしないことを確認。
- 実際にAppから3ページPDFをダウンロードし、ページ数・描画された20°・枚数を確認。
- 詳細・シンプル表示の往復でも、同じ条件の完成済み1枚PDF・3枚PDFのURLと配置を保全。
- 実Appの「再取得」で同じ範囲のDEM取得版を更新。古い選択筆キャッシュより新しい取得を選び、旧保存リンクを破棄して再計算した後、シンプルと3枚レポートの取得日時・座標を一致させました。
- 全自動検査554/554、ビルド、CSP、同梱資産検査が通過。既存の固定依存を複製し、新規インストールやPCの権限・セキュリティ設定変更なし。

前後のJSON・PDF・画面は `outputs/app-layout-sync/before/` と `after/`（Git対象外）。一度にサーバー1個・ブラウザー1個を使用し、各検証のfinallyで終了しています。実候補地・外部実取得・Mac/Safari・実印刷は未検証です。初期調査の90°では既存エンジンが形状確認中止となる合成例があり、今回は計算エンジン自体を変更せず、有効な135°と南向き・最適で状態一致を検証しました。

# v1.28 ブラウザー確認記録

確認日：2026-10-08（日本時間）。業務用Windowsで確認。公開サイトの更新記録ではありません。

## 実際に確認した流れ

- 社内案件1件の画像由来の参考範囲を使用。個別案件の名称・座標・記録ファイルは公開リポジトリに含めていません。
- 範囲の取得後、同じ範囲の地図表示・等高線と勾配の平面図・実DEMによる3D・日本語A3地形図面が表示されることを確認しました。
- アプリが生成した地形PDFの2ページをファイルとして確認。両ページともA3横、約240dpiのJPEG画像で、文字・図・凡例・出典・ページ下部の重なりがないことを目視確認しました。
- 記録保存で生成したschema 3ファイルを読み込み、範囲・高低差・局所勾配・取得時刻が復元されることを確認しました。
- 発電量の別画面へ移動して戻ったとき、地点・範囲・地形結果が保持されることを確認しました。地平線・積雪・レポートは上部ツールメニューから直接移動できます。
- 390×844の一時表示幅で、平面図・地形レポートの横方向のはみ出しがないことを確認しました。
- PDF生成後に説明欄を開閉しても、生成済みPDFのダウンロードリンクが残ることを確認しました。

## 追加した操作の確認

画面3Dのマウスドラッグで方位と見下ろし角が変わること、矢印キーで回転すること、最初の視点に戻せることを実ブラウザーで確認しました。主な範囲ボタンは地図上の「範囲を描く」「除外」の2個です。地番ファイルと対象・参考の選択は基本閉じた詳細にまとめています。

開始点を再クリックして除外図形が完成すること、2点では完成せず案内が出ること、3点以上では「確定」ボタンも使用可能であることを確認しました。最初の点には約44pxのクリック範囲を用意しました。実タッチ端末の操作は未確認です。

大きな範囲は、PDFの2つの3D図が数万のSVG面になるため30秒の制限に達する可能性があります。今回の実案件規模の確認を最大範囲のPDF成功とは扱いません。

## 確認中に修正した内容

- 地図への投影に原点オフセットを明示し、非数値座標を防止。
- 地形レポートへ200m断面の全範囲を渡すように変更。欠測点を削除して隣接しない点を結ぶ処理も除去。
- DEM1Aの出典をDEM5として数える集計を修正。未取得点を有効標高の比率の分母から除外。
- レポート表示の更新で生成済みPDFリンクが消える処理を修正。出力内容に関係する変更時だけ古い出力を無効化。
- 面取得とPDF生成に時間制限と後処理を追加。中断した処理が新しい結果を上書きしないことを自動テストで確認。

## 未確認の範囲

Mac・Safari実機、プリンターへの出力、複数人での資料読解、実測境界との一致、施工判断は未確認です。200m断面の表示範囲と欠測の扱いは自動テストで確認しましたが、今回の実ブラウザーの取得完了までは確認できていません。

ブラウザー接続経由の自動ダウンロード完了通知は得られませんでした。画面上に残るダウンロードリンクから生成データを取り出し、PDFの構造と実ページを検査しました。OSのダウンロードフォルダーへの自動保存が確認済みだとは説明しません。

画像から復元した参考線は確定境界ではありません。登記面積に合わせて図形を拡大する処理や、面積から設備容量・収益・施工可否を自動判断する処理は実装していません。

次の受入確認は実案件3件です。従来手順との時間比較、出典と未確認事項の漏れ、初見の読者の理解、SolarPro/CAD担当者の再利用を記録します。これを確認する前に有料化の妥当性が検証済みとは扱いません。

最新の作図UIでは地図上の2個の独立したボタンに変更し、地番・範囲詳細は地図下の一行へ移動しました。作図中だけ既存地形・保存境界・断面を薄くし、作図開始時に地図へ移動します。初期化は現在地ボタンの隣へ移動し、従来の作業初期化を呼び出します。

実ブラウザーの最新表示で、作図開始時に範囲色のopacityが0.64から0.12、等高線のstroke-opacityが0.18へ変わり、同じボタンで作図を終了すると元へ戻ることを確認しました。390×844で文書幅が表示幅と一致し、地図上の2ボタンが44pxの高さで重ならないことも確認しました。

初期化の最終点検で、現在地取得中に初期化した場合の待機状態を解除する修正を追加しました。390×844の表示で「現在地を取得」と「初期化」が同じ行に並ぶことを実ブラウザーで確認しました。利用中の候補地を消さないため、この最終確認では利用者の画面の初期化ボタンは押していません。

住所検索を「候補地を探す」の隣へ移動しました。デスクトップ1342px幅では見出しと検索が同じ行、選択地点・座標・標高・コピー・断面操作が高さ61pxの一行に並ぶことを確認しました。表示座標は小数6桁、コピー操作は従来の値を使用します。内側の大きな断面カードと繰り返す説明を削減し、断面の距離・確認ボタンは直接表示します。

390×844では検索が見出しの下へ移動し、検索入力と検索ボタンは高さ44pxの一行です。文書幅375pxと表示幅375pxが一致し、コピー・断面ボタンは44px、地点情報と断面操作の領域は約137pxでした。長い住所・コピー後の状態文は隠さず折り返します。実端末のタッチ操作の確認とは区別します。

検証用SSRサーバーの不要なファイル監視とWebSocketを止め、準備30秒・パッケージ用全テスト120秒の制限を追加しました。これは検証環境の変更で、利用者向けのAPI待ち時間を変更するものではありません。

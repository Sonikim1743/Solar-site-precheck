# 座標リンクと地点のコピー — v1.28.5

Excel等の住所表示に、確認済み地点のアプリURLをハイパーリンクとして設定できます。アプリは住所を再検索するのではなく、URLの十進度座標を使用します。リンクの作成だけで地番や所有者を確定しません。

```text
https://solar-site-precheck.pages.dev/?lat=34.4089&lon=133.2049
https://solar-site-precheck.pages.dev/?lat=34.4859&lon=133.3628
```

`lat` は緯度、`lon` は経度で、それぞれ1個だけ指定します。対応範囲は緯度20〜50・経度120〜155。欠落、空欄、非数値、指数表記、重複、範囲外はエラーになります。氏名・個人住所・PDF内容はURLに入れません。公開例の座標は動作例であり、候補地や地番の確認結果ではありません。

リンクを開くと地図の指定地点へ移動し、「検討範囲の等高線・勾配・3D」を開きます。地図を見て範囲を描くか参考地番を選択・確定し、地形取得を実行します。境界の自動生成、地形の自動取得、候補登録、外部への連絡はしません。

## 保存中の作業との関係

- 有効・無効の座標リンクは、既存のブラウザー保存を読み込まず、自動保存もしない一時検討です。別の地点のメモ・範囲・分析結果を混在させません。
- 一時検討で変更した内容は、必要に応じて検討記録JSONへ保存してください。再読み込み・別地点のリンク・履歴での地点変更は新しい一時検討になります。
- 「保存中の作業を別タブで開く」は座標パラメーターを除いた通常画面を開きます。通常画面の従来の保存・復元は維持します。通常画面同士の複数タブ保存競合を解消する更新ではありません。
- 同じ座標のまま折りたたみや発電量画面へ移動しても、座標リンクの一時検討を初期化しません。

## 地点の操作

「度・分コピー」は従来表記を保持します。「緯度経度コピー」は実際の選択座標を `緯度, 経度` の順でコピーし、成功・失敗を表示します。クリップボードを使えない場合は表示された座標を手動でコピーできます。

Googleマップとストリートビューは公式Maps URLsで選択地点を別タブに開きます。ストリートビュー画像がない地点もあります。Mapionは中心点を開く手動確認です。「?」から案内を開き、「＋便利ツール → 地図URL」で中心点のMAPCODEを確認・コピーします。日本のカーナビ用MAPCODEの自動変換・自動コピーは未対応です。

外部ボタンは有効座標がある場合だけリンクを持ちます。クリックするまでGoogle・Mapionへの追加取得は行いません。APIキー、埋込み、隠しAPI、スクレイピングは使用しません。

参考：[Google Maps URLs](https://developers.google.com/maps/documentation/urls/guide)、[MapionのMAPCODE案内](https://help.mapion.co.jp/search/mapcode.html)、[DENSOのMAPCODE案内](https://www.denso-solution.com/mapcode/en/howto02.html)。Mapionの[リンク案内](https://help.mapion.co.jp/link/company.html)も参照してください。

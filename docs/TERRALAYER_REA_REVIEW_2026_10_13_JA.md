# TerraLayerの電力表示を参考にした改善検討

2026年10月13日。Solar Site Precheckの電力情報を、土地の一次検討に使いやすくするための調査記録です。TerraLayerのデータ・プログラムを当アプリへ移植した記録ではありません。

## 調べた範囲

[TerraLayerの地図画面](https://terralayer.jp/plugins/map_basic/)で実際に読み込まれたスクリプトの一覧を確認し、そのうち同一サイトの公開JavaScriptを7本、ログイン情報を送らず取得しました。HTTP 200で取得できた原本にはURL・取得時刻・SHA-256を記録しました。

送電線の取得条件と非同期応答の処理を行う6関数だけを正確な開始・終了位置で切り出し、REAで静的解析しました。対象は計8,116バイト、構文解析成功6本、構文エラー0件、確認した構文ノード875個です。解析上限は各ソース30秒・256MiBでした。抽出元との対応はUTF-8バイト位置と文字位置の両方で記録しています。

外部関数や画面の状態に依存する意味関係は218件が未確定です。これは限定した関数の解析であり、サービス全体やサーバー側を解明したとは扱いません。取得したプログラムは解析用に実行せず、APIを独立して直接呼び出すこともしていません。実画面では通常の送電線・鉄塔表示をON/OFFして観察し、元のOFF状態に戻しました。原本・解析資料・実画面は公開リポジトリと分離して管理します。

| 項目 | 確認結果 | 当アプリに役立つ点 |

| 電圧 | 送電線は最小・最大電圧を条件として渡し、地域に応じた選択肢を取得する処理でした。 | 既存資料にある電圧で絞り込み、未記載を推測で埋めない。 |

## 今回確認していないこと

- **電柱の表示は確認できていません。** 今回確認した画面の名称と7本のスクリプトからは、鉄塔と別の電柱レイヤーを示す根拠を得ていません。他の画面も含め機能が存在しないと断定するものではありません。
- 元CSVの内容、原資料の利用条件、属性同士の照合精度、現時点の設備位置・容量は未確認です。表示項目があることは、その値が全設備に揃っている証拠ではありません。
- 近くに設備があること、表示された空容量、線名の一致だけでは、対象地の連系可否や引込方法を確定できません。
- 今回の静的解析はセキュリティ診断でも、利用規約に関する法的評価でもありません。取得できたことだけでコードや資料の再利用条件を満たしたとは判断しません。

## Solar Site Precheckへの独立した適用順序

| 優先 | 改善 | 完了の目安 |
| --- | --- | --- |
| P0 | 既存の電力確認画面で、変電所・送電線・鉄塔・電柱を実データの種別に応じて整理する | 当アプリが使うOSM等の取得済みデータだけで表示し、鉄塔と電柱を混同しない。未取得・未収録・表示OFFが区別できる。 |
| P0 | 会社名・電圧・名称と、出典・元資料の日付を同じ対象の詳細で読む | 未記載を推測しない。地図設備と公式資料の対応が未確認なら、その状態を明示する。 |
| P1 | 見る対象に応じた表示切替と絞り込みを簡潔にする | 初期画面をラベルで埋めず、必要な種類だけ表示できる。条件変更・画面往復で候補地や検討範囲を失わない。 |
| P1 | 表示結果を次の確認事項へつなげる | 「候補の設備」「まだ確認できない属性」「電力会社資料で照合する項目」を短く示し、容量や接続先を自動確定しない。 |

取り入れるのは、情報の分け方・資料の鮮度の示し方・表示量を抑える考え方です。実装は当アプリの既存コードと独立したデータ源に基づいて行います。TerraLayerの取得原本、内部API、会社アカウントの画面や個別土地情報は配布物へ含めません。

この調査単独で新しい公開版の完成は宣言しません。実装後の操作確認、既存データとの整合、Macでの再開、公開更新は、それぞれの検証記録で確認します。

# v1.28.6 更新内容 — 2026-11-09

## 地図から3Dへ

- 地図の作図・表示ボタンを地図外へまとめ、主要操作を44px以上に統一しました。通常のホイールはページ移動、ONにしたときだけ地図を拡大します。デスクトップでは作図・地番選択を始めてもホイール設定を勝手にONへ変更しません。
- 「3D地形分析」から「範囲を3Dで見る」へ進み、取得後は3Dを先に表示します。地平線・積雪・規制の補足確認は、その後ろで必要なときに開きます。
- 画面を往復しても選択地点・範囲・取得結果・3D視点を維持します。記録保存はツールとレポート内にあります。

## 修正と表示の整合

- 複数の公開地図参考領域を結合したとき、共有辺の追加頂点により3Dへの適用が失敗する場合を修正しました。穴・分離部分・除外・不正図形の拒否を保持します。測量境界の精度保証ではありません。
- 住所検索は返却名と入力名を確認します。名称が一致する1候補だけを自動選択し、省略された地域名や複数候補は利用者が選びます。地番位置は引き続き未確認です。
- 手動編集した地平線を保存・再開した後も「手動編集あり」と表示します。樹高仮定による計算結果と混同しません。
- PDF・登記等の画面へ移動すると、非表示の地図見出しではなく表示先の見出しへキーボードフォーカスを移します。遅れて読み込む画面にも対応します。
- 規制の自動照合案内を実際の収録資料に合わせました。埋蔵文化財・農業地域・洪水・土砂の参考照合と、用途地域・筆ごとの農地等の別途確認を区別します。
- README、更新手順、配布案内を現行の操作・版・PDF出力の説明にそろえました。既存の発電量計算・公表設備資料・利用者メモは維持し、補足チェックの主結果として数値や一般説明を増やしていません。

## 配布範囲

Webとソースの更新です。既存Windows自動更新ZIPとそのメタデータはv1.28.3のままです。Web用パッケージは約304MBで、GitHubの通常ファイルとしては公開しません。Web専用の検証・パッケージ作成は pnpm package:web を使い、旧ZIPのメタデータを変更しません。各PCのインストール更新とは別です。

採用対象はPR #9と#10の現在の試用版、および上記レビュー修正です。別の規制相談・記録連携のPR #8は含めません。

## 検証と限界

自動試験・ビルド・配布検査、公開後のID・ソース・ハッシュ、実際の画面確認は [公開記録](DEPLOYED_VERSION.md) に記載します。資料なし・取得失敗・欠測・未検出を安全や事業可否へ置き換えません。敷地全体・現行指定・許認可・法的境界は未確定です。

Mac/Safari・実機タッチ、全PDF操作、実測との精度照合、通常画面同士の複数タブ保存競合、別環境の記録互換は今回の完了対象ではありません。参考配置の条件・個別除外はJSON保存対象外です。現在の適用結果は配置図PDF・地形報告書・DXFで出力できます。個別案件、実資料、認証情報、試験画面は公開ソースへ含めません。

# v1.27.1 단일 페이지 브라우저 확인
기준일: 2026-09-24. **최종 단일 페이지 구성의 데스크톱 확인을 완료했다. 공개 배포 완료 기록은 아니다.**
브라우저 조작 담당자가 실제 사용자 작업 주소 127.0.0.1:5273에서 확인한 결과와 화면 기록을 전달받아 정리했다.

## 이번 최종 구성에서 확인한 항목
| 항목 | 실제 확인 결과 |
|---|---|
| 같은 페이지의 핵심 섹션 | 분석2 / G 발전량 / 3 레포트 / 4 자료 / M SolarPro 매뉴얼 / 활용 예시가 모두 같은 DOM에 존재함 |
| 기본 표시 | 위 상세 섹션은 모두 기본 접힘이며, 하단 카드 순서 2 → G → 3 → 4 → M을 화면에서 확인함 |
| 분석2 열기 | 지평선·적설·검토 기록 메뉴가 함께 보임. 지도와 레포트 섹션은 같은 페이지에 유지됨 |
| G 발전량 열기 | 계산조건의 용량50이 유지되고 지도도 같은 페이지에 남아 있음 |
| 핵심 기능 찾기 | 다른 전용 화면으로 옮기지 않고 같은 페이지의 제목·메뉴에서 필요한 항목을 열 수 있음 |
| GEONEX | 확인용 외부 링크가 없음을 확인함 |

이 결과는 단일 페이지의 기능 존재·접힘·섹션 접근·확인한 입력값 보존에 대한 검증이다. 모든 자료 취득이나 계산 요청을 새로 실행했다는 뜻은 아니다.

## 이전 중간안에서 확인한 참고 동작
화면 분리 중간안에서는 검증용 합성 연간60,000 kWh와 레포트 반영, 예제 미리보기 → 적용 → 되돌리기, 원래 위치의 화면 왕복 보존, 지평선 메뉴의 상세 접힘 열기를 확인했다는 기록이 있다. 합성값은 실제 PVGIS 취득값이나 실제 발전 실적이 아니다. 이 이력과 위 최종 단일 페이지 구성 확인을 구분한다.

## 한계와 별도 확인
- 모바일의 이번 최종 단일 페이지 구성·메뉴·지도 조작은 아직 확인하지 않았다.
- 전용 화면 분리안은 철회했으므로 적용 전 비교 입력의 ‘다른 화면 왕복’은 이번 최종 구조의 검증 대상에서 제외한다. 컴포넌트 상태 보존 보강은 유지한다.
- 기록 저장/재열기·계산 수치의 자동 테스트와 빌드 결과는 별도 실행 기록을 따른다.
- 최종 소스 커밋·배포 ID·운영 URL 확인은 DEPLOYED_VERSION.md에 기록한다. 메뉴 이동 확인을 실제 지평선 재분석이나 NEDO 자료 취득 성공으로 확대 해석하지 않는다.

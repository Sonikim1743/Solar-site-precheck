# 保存型ハザード（岡山・広島・山口）

岡山・広島・山口の土砂A33-2025、県管理洪水A31a-2025、中国地方整備局の国管理洪水A31a-2025を使用する。洪水は「想定最大規模」のみで、計画規模・継続時間・家屋倒壊・内水・高潮・津波は今回の表示に含めない。原本の収録河川・指定資料に限られ、県全域の調査完了を意味しない。

対象県はN03-2025（2025-01-01）の実際の行政境界面で照合する。境界上・複数県・取得失敗は未確定とし、最近傍や矩形だけで県を決めない。対象3県ではハザードのための外部逆ジオコーダーを使わない。住所表示・背景地図は別機能であり、外部通信やその失敗は残り得る。保存型対象外は従来の外部画像方式で、保存型の全国対応ではない。

JGD2011経緯度（EPSG:6668）の原本座標を保持し、丸め・単純化・測地変換を行わない。MultiPolygonの構成面は穴を保って分割し、表示と地点照合に同じ座標を使う。分割した面は原本レコードIDでまとめて表示する。土砂の線資料は線で表示するが、線から面を作らず地点の面判定に使わない。表示上限や一部取得失敗がある場合は未確認とする。

圧縮ZIP原本と取得日時・SHA-256は非公開の作業資料に保存する。公式GeoJSONの対象部分を分割・gzip圧縮し、単一資産25MiB未満・保守的な全サイト20,000ファイル未満を検査する。大きな単一面は境界を変えず圧縮し、展開サイズに上限を設ける。処理能力の低い端末では大きな面の展開・描画が重くなる可能性がある。

変換は別の作業領域へ書き、再読込・座標と属性の一致・ハッシュ・件数を検証してから版フォルダーを確定し、`current.json`だけを原子的に置換する。変換失敗では最後の正常な版を変更しない。古い版の自動削除や原本の上書きは行わない。ブラウザーは同じ版を共有キャッシュし、版の切替後は再読込で新しい版を取得する。一般的なブラウザーキャッシュだけでオフライン保存・完全な最新性を保証するものではない。

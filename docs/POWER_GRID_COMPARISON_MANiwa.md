# 同一地点の比較・未解決事項

対象座標: 34.973013, 133.627717（2026-09-09確認）

| 項目 | TerraLayer画面 | 本アプリ（修正前） |
|---|---|---|
| 送電線 | CSV由来候補 上水田線 2.11km | 名称未記載110kV線 5.1km |
| 変電所 | 上水田配電塔 2.22km、22/6kV | 取得済み10km圏で0件 |
| 検索条件 | 表示11〜77kV | 66・77kV優先の段階検索 |
| 取得状態 | 表示あり | 20kmへの拡大中に利用制限、10kmまで |

## 確認した原因

1. 22kV設備も含む近接確認と66・77kV優先検索を混同していた。
2. 連続した範囲拡大でOverpassの利用制限に達し、未完了となった。
3. 本アプリの公式CSVには上水田線（岡⑤F3、22kV）と上水田配電塔（岡⑤H3、22/6kV、空容量1MW、上位0MW）があるが座標がない。地図側に一致する設備がなければ結合できない。
4. 地図の描画件数を線80件・変電所60件で切り捨てていた。

## 修正

- 初期検索を電圧指定なし・10kmの単一取得とし、20/50km拡大は明示選択。
- 66・77kV優先は別の選択条件として維持。
- 条件変更後の未取得状態と表示中の取得条件を明記。
- 専用地図では取得済み設備の固定件数による切り捨てを撤廃。
- 長い重複メッセージを整理。

## 未解決

上水田線の線形および上水田配電塔の位置を独立した利用可能な地理データで確認できていない。TerraLayerの画面上の距離だけから座標を逆算したり、近隣の線に公式名称を付けたりしない。

公式資料: https://www.energia.co.jp/nw/service/retailer/keitou/access/pdf/mapping_oka.pdf
REPOSにも送変電設備レイヤーはあるが、搭載一覧で当該設備のGISダウンロードリンクは掲載されていない。これだけで再利用可能なデータ供給元を確保したとは扱わない。

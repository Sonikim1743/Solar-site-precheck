# 프로젝트 목적과 결정 — 2026-10-08

## 무엇을 만드는가
일본의 태양광 후보지를 찾고, 발전량·주변 지형·적설·계통 정보를 같은 후보지 기준으로 정리하여 SolarPro와 CAD의 상세 설계 전에 검토 근거를 만드는 웹앱이다. 자동 투자 판정이나 계통 접속 승인을 대신하는 제품은 아니다.

사용자는 프로듀서 관점의 전체 흐름·정보의 쓸모·수익화 조건·화면의 간결함을 중시한다. 사용자와의 대화·진행 보고는 한국어, 앱과 사용자에게 전달하는 검토서·문서·그림은 일본어다(2026-09-24 명시 요청).

## 최신 제품 원칙 — 메인 흐름 유지, 발전량만 별도 화면
사용자는 기존 메인의 지평선·적설·레포트·자료·SolarPro 접이식 구성을 유지한다. **v1.27.2의 최신 명시 요청은 발전량만 초기 메인에서 빼고 상단 메뉴로 여는 별도 화면에 두는 것이다.** v1.27.1의 모든 기능을 같은 페이지에 두는 원칙에서 발전량에만 예외를 적용한다. 다른 기능까지 분리하는 방향으로 확대하지 않는다. v1.27.2는 GitHub·Cloudflare·Windows 갱신과 검증을 완료했다. 실제 증거와 한계는 DEPLOYED_VERSION.md를 따른다.

- **메인 작업 흐름 유지:** 지도에서 고른 후보지를 기준으로 지평선·적설·필지 검토·레포트·자료·SolarPro 준비를 메인의 접이식 구성에서 이어간다. 발전량만 상단 메뉴의 이름으로 바로 찾을 수 있는 별도 화면에 둔다.
- **기본 조작은 바로 보임:** 단면 버튼은 추가 접힘 없이 항상 보이게 한다. 지점·표고·복사 항목은 간격을 정리하여 정보와 조작을 구분한다.
- **짧은 섹션 제목과 요약:** 무엇을 하는 곳인지 바로 알 수 있게 하고, 설명과 상태 문구를 상시 반복하지 않는다.
- **상세는 기본 접힘:** 메인의 기존 접이식 구조와 필지 검토를 유지한다. 발전량 화면의 계산조건·비교조건·상세 수치는 필요할 때 열되, 결과가 없으면 필수 입력을 사용할 수 있어야 한다. 단면 버튼을 이 원칙으로 다시 숨기지 않는다.
- **핵심 기능을 숨기지 않음:** 간결함은 기능 삭제나 여러 단계 뒤로 감추는 것이 아니다. 메뉴를 한 번 열면 「地平線・日影を計算」「積雪データを見る」「レポート」를 이름으로 찾고, 같은 페이지의 해당 영역·상세 접힘을 바로 열 수 있어야 한다.
- **지점·입력 보존:** 섹션을 열고 닫거나 발전량 화면을 왕복해도 위치·입력·검토 필지·계산 결과를 유지한다. 다른 후보지를 명시적으로 선택할 때만 기존 결과의 유효성을 처리한다.
- **실사용 확인:** 변경한 기본 조작과 발전량 화면 왕복을 실제로 확인한다. 데스크톱·모바일의 확인 범위와 한계를 기록하며, 코드 검사만으로 간결함과 사용성의 완료를 판단하지 않는다.

GEONEX 확인 탭·버튼·외부 확인 링크 삭제는 유지한다. GEONEX 재도입이나 API 연동은 현재 다음 과제가 아니다.

## 현재 개발 후보 — v1.28.0
`feat/terrain-area-v1.28`에서 범위의 실DEM 지형·등고선·경사·3D와 일본어 A3 보고서를 로컬 구현 중이다. 아직 공개 배포하지 않았다. 공개·Windows 운영본 v1.27.2의 기존 완료 근거는 `DEPLOYED_VERSION.md`에 보존한다. 후보의 검증 결과·소스 커밋·배포물 해시·배포 ID·공개 확인은 각각 실제 확인 후 별도로 기록한다.

이번 코드 작업은 사용자가 Windows에서 진행하도록 명시 승인한 예외다. 향후 Mac OpenClaw 중심 개발이라는 기본 방향은 유지하며, Mac 실기 확인을 이번 Windows 결과로 대신하지 않는다.

새 지형 검토는 지도 아래 기본 접힘 영역 하나에서 사용한다. 선택 지점과 검토 범위를 구분하고, 대상·지정 범위·제외를 반영한 같은 유효 범위와 표고를 지도·평면·3D·보고서에 사용한다. 화면의 3D는 드래그·화살표로 시점을 돌려 보고, 보고서는 고정된 두 시점을 사용한다. 높이 과장 없이 1:1이며 결측·제외부를 채우지 않는다. 자료 해상도와 5m 표시·집계 간격을 구분하고 경사색으로 시공 가능·불가능을 자동 판정하지 않는다. 지형 보고서는 A3 가로 두 쪽의 별도 선택이며, 이미지 형식 PDF를 브라우저 안에서 만든다. 세부 조건은 `TERRAIN_AREA_V1_28_KO.md`를 따른다.

## 계산과 자료의 기존 원칙
- 주소/지도 → 필요한 검토 → 계통 확인 → 보고서의 연결을 같은 후보지 기준으로 유지한다.
- 발전량은 연간 핵심값·월별 그래프를 먼저 보여준다. 계산조건·비교조건·상세 수치는 필요한 때 열고, 결과가 없으면 계산에 필요한 조건을 보여준다.
- 적설과 지형은 가정이 드러나는 비교 계산으로 기본값과 구분한다. 적설은 같은 3차 메쉬의 NEDO 자료를 확인하고, 주변 지평선과 PVGIS 지형 계산에서 손실을 중복 적용하지 않는다.
- 주변 설비 거리나 이름 일치만으로 여유 용량·접속 가능성을 확정하지 않는다. 자료 기준일·일치 근거·미확인 조건을 남긴다.
- 기록 저장/읽기는 필요한 때 여는 작은 메뉴에 둔다. 보고서의 발전량은 연간·월별 값과 조건을 함께 확인할 수 있게 한다.
- 대상 필지는 합집합, 참고 필지는 면적 제외. 검토 범위가 있으면 대상 필지와 공통 부분을 사용하고, 제외 범위의 중복을 제거해 차감한다. 대상 필지가 없으면 그린 범위를 기준으로 쓴다.
- 필지 추가만으로 계산 지점을 옮기지 않는다. 명시적인 지점 선택 후 해당 지점의 발전량·지형을 다시 계산한다. 대표점 한 곳이 토지 전체를 대변하지는 않는다.

v1.27.1과v1.27.2의 과거 배포·화면 확인 근거는 `DEPLOYED_VERSION.md`와 각 버전 확인 문서에 보존한다. 과거 `RELEASE` 문서는 당시 변경 이력이며 현재 후보의 완료 근거가 아니다. 실제 토지 조사·CAD/SolarPro 원본·비공개 업무 이력은 별도 비공개 인수인계 자료에 있다. 개별 안건의 좌표·지번·원자료 이름·후보지 기록은 공개 소스와 배포물에 포함하지 않는다.

최신 범위 조작은 지도 위의 「範囲を描く」「除外」 두 버튼이다. 같은 버튼을 다시 누르면 작도를 종료한다. 파일·지번·면적·관리는 지도 아래 한 줄의 「範囲・地番の詳細」에서만 펼친다. 처음 점 재클릭과 기존 확정 버튼을 함께 제공한다.

# v1.28 범위 지형 검토

사용자가 이번 구현을 업무용 노트북에서 진행하도록 승인했다. 이후 Mac OpenClaw 인수 방향은 유지한다. 현재 공개 v1.28.0과 후속 v1.28.1의 개발·검증·패키지·공개 배포 상태는 구분한다. 이 문서에는 개별 토지 자료를 포함하지 않는다.

## 제품의 우선순위

SolarPro/CAD 상세 설계 전에 같은 토지를 가리키는 검토 근거를 만든다. 지도에서 범위를 확인하고, 같은 범위와 표고로 등고선·경사 색상·실DEM 3D·일본어 보고서를 이어간다. 기능을 많이 늘리거나 면적만으로 설비용량·투자수익·시공 가능 여부를 판단하지 않는다.

기존 메인의 접이식 구성과 직접 보이는 단면 버튼을 유지한다. 발전량은 기존 상단 메뉴의 별도 화면에 둔다. 신규 지형 패널은 지도 아래 한 개의 기본 접힘 영역으로 제공한다. 설명과 근거는 필요할 때 펼친다. 범위 설정의 기본 버튼은 검토 범위와 제외 범위 두 가지로 정리하고, 원자료 파일·대상/참고 필지 선택은 접힌 상세 한 곳에 둔다. 세 점 이상 지정한 뒤 시작점을 다시 누르면 같은 도형 검증을 거쳐 완성하며, 기존 확정 버튼도 유지한다. GEONEX 확인 탭은 되살리지 않는다.

## 같은 범위의 처리

- 대상 필지의 합집합과 지정 검토범위의 공통 부분에서 제외 영역의 합집합을 뺀다. 참고 필지는 집계하지 않는다.
- 평면·3D·집계·지형 보고서·CSV·기록이 같은 유효 도형을 사용한다.
- 유효 범위 변경 시 이전 결과를 숨기고 실행 중인 요청을 취소한다. 다른 참고 필지의 변경처럼 유효 범위가 같은 경우는 결과를 유지한다.
- 새 기록은 schema 3이다. 표고 원자료와 출처·취득 시각을 저장하고 경사·등고선·통계는 열 때 다시 계산한다. schema 1/2도 계속 열 수 있다.

## 표고와 경사

국토지리원 PNG 표고 타일을 사용한다. DEM1A → DEM5A → DEM5B → DEM5C → 10m DEM 순으로 필요한 점만 보완한다. 공식 목록에서 TXT 표고 타일은 2024년 10월 이후 갱신하지 않는다고 안내하므로 새 점·단면·면 계산에서 TXT를 쓰지 않는다.

표시·집계 격자는 5m, 국소 경사는 동서·남북 각 10m 폭의 중앙차분이다. 원자료의 1/5/10m급 해상도는 별도로 표시한다. 표시 격자를 측량 정확도로 설명하지 않는다. 화면 3D는 드래그·터치·화살표로 방위와 내려다보는 시점을 바꿀 수 있다. 기본은1:1이고, v1.28.1부터 사용자의 요청으로 「高さ2倍 1:2」를 별도 제공한다. 가로1:세로2의 표시 강조이며 자동 화면 맞춤 때문에 최종 픽셀 높이가 항상 정확히 두 배가 되는 뜻은 아니다. 표고·경사·색·분포는 변경하지 않는다. 배율 전환은 방위·시점각·줌을 보존한다. A3보고서는 고정 시점 두 개와1:1을 유지한다.

결측·제외 영역을 임의로 채우지 않는다. 경사 비율의 분모는 유효 범위 안에서 경사를 계산할 수 있는 격자점이다. 등기 면적을 분모로 쓰지 않는다. 혼합 표고 출처와 부분 결측의 한계를 표시한다. 중앙값은 양 끝점 평균 경사와 다르다.

v1.28.1의 추가 요청으로 경사 비율 옆에 「推定面積」를 표시한다. 제외 후 유효 도형 면적 × 경사 계산 가능 격자점 비율 × 해당 경사 구간 비율로 환산하며, 원래 비율의 반올림 전 값을 사용한다. 결측에 해당하는 면적은 「勾配未確認」으로 별도 표시하고 확인된 구간으로 확대 배분하지 않는다. 실제 경사별 경계를 측정한 면적이나 설치 가능 면적이 아니며 1:1/높이2배 전환에 따라 바뀌지 않는다. 화면·A3 범례와 보고서 표는 같은 환산값을 사용한다.

3D는 표면 아래에 중립 회색의 측면과 바닥을 붙인 블록으로 표시한다. 바닥은 실제로 그릴 수 있는 표면 범위만 사용하며, 작은 제외 구멍·결측·분리된 범위 사이를 채우지 않는다. 측면은 외곽과 공극 경계에만 만들고 내부 격자 사이에는 만들지 않는다. 평탄한 지형도 입체로 보이도록 표시 바닥은 표면의 가장 낮은 보간점보다 최소5m 아래의5m 단위로 정하지만, 이 표시 깊이는 표고·고저차·토량 집계에 포함하지 않는다. 화면과 고정 시점 보고서에 같은 블록을 사용한다. 측면·바닥은 지층·지하 구조·실제 절토면을 의미하지 않는다고 일본어로 표시한다.

조작은 「回転」과 「視点の移動」 두 가지다. 사용자의2026-10-08 정정에 따라 시점 이동은 지형 중심을 고정하고 좌우 드래그·화살표로 보는 방위를 바꿔 둘레를 돌아 옆면을 확인하는 방식이다. 화면상의 평행 이동은 제거했다. 위로 드래그하면 내려다보는 각도가 커져 위에서 보는 느낌을 준다. 회전 모드의 기존 위아래 드래그 방향은 유지한다. 직교 투영을 유지하므로 원근 카메라의 실제 위치·거리 계산을 의미하지 않는다. 방위는360° 순환하며 시점각 범위는0–75°다. 줌·높이 강조 전환은 방위와 시점각을 보존하며 초기 시점 버튼·Home으로 처음 시점에 돌아간다. 지형 위에서 휠과 확대·축소 버튼으로0.65–2.5배를 조절하고, 지형 밖의 페이지 스크롤은 유지한다. 화면 배율은 표고·통계·1:1 비율과 보고서의 고정 시점을 바꾸지 않는다.

새 면·점 PNG 요청은 전역 최대 4개이며 성공 타일만 보관한다. 취소·실패 후 재시도와 늦은 응답을 처리한다. 면 계산은 30초 제한, 타일 취득은 8초 제한이다. 점 표고의 PNG 실패 시 기존 JSON API의 추가 최대 8초 조회가 가능하다. 이 제한을 브라우저 파일 선택 도구의 응답 제한과 혼동하지 않는다.

## 보고서와 기록

지형 도면은 A3 가로 두 쪽이다. 첫 쪽은 유효 범위·등고선·경사 분포와 읽는 법, 둘째 쪽은 같은 표고의 서로 다른 시점 3D와 출처·계산 조건·현장 확인 사항이다. 기존 후보지 체크 보고서와 독립적인 도면 선택으로 제공한다. 긴 현지 메모는 발췌임을 표시하고 원문은 기존 보고서와 검토기록에 유지한다.

일반 후보지 보고서는 기존 인쇄 기능을 유지한다. 범위 페이지는 국토지리원 표준지도에 대상·참고·검토·제외선을 동일 Web Mercator 좌표로 겹치고, 면적과 같은 범위의 고저차·국소 경사, 다음 현장 확인사항을 연결한다. 배경 타일은 표시 영역만 최대20개이며 새 주소 조회를 추가하지 않는다. 배경 로딩 중/실패 안내를 구분하므로 지도가 표시된 뒤 인쇄한다. 범위가 바뀌면 이전 지형 수치를 재사용하지 않는다. 지도 지역명은 현재 선택 지점의 기존 주소를 재사용하며 경계 이름을 뜻하지 않는다. 3D와 평면 범례에 표시하는 경사 비율은 보고서와 같은 실제 summary.slopeBins를 사용한다. 지형 PDF는 브라우저에서 도면과 일본어 본문을 이미지로 저장하므로 텍스트 선택·CAD 편집 파일이 아니다. 지형 PDF 생성에 외부 업로드를 사용하지 않는다.

PDF 생성은 전체 30초와 각 비동기 처리 15초 제한을 적용한다. 취소·오류 때 임시 이미지와 파일 주소를 정리하고 재시도할 수 있게 한다. 자동 다운로드가 브라우저에서 처리되지 않으면 화면에 남는 PDF 다운로드 링크를 사용한다.

기록 저장은 후보지와 조건·범위·표고 원자료를 다시 여는 보조 기능이다. 첫 화면의 주 작업으로 확대하지 않는다. PDF 원본·모든 계통 지도·설계 프로그램의 편집 상태는 기록 대상이 아니다.

## 검증과 다음 결정

단위 검증 외에 실제 브라우저에서 범위 선택 → 취득 → 지도 → 평면/3D → 보고서 → 기록/PDF를 확인한다. 실패한 시도와 수정 후 확인을 함께 기록한다. Safari와 Mac은 실제 확인하지 않은 경우 미확인으로 남긴다.

수익화는 다음 세 안건 시험의 결과로 결정한다. 비교 기준은 검토에 걸린 시간, 출처 누락, 첫 독자의 이해, 다음 작업자의 재사용이다. 가격·유료화의 타당성을 이미 검증했다고 쓰지 않는다. 새 기능을 추가하기 전에 이 흐름을 실제 업무에서 사용할 수 있는지 먼저 확인한다.

최신 범위 조작은 지도 위의 「範囲を描く」「除外」 두 버튼이다. 같은 버튼을 다시 누르면 작도를 종료한다. 파일·지번·면적·관리는 지도 아래 한 줄의 「範囲・地番の詳細」에서만 펼친다. 처음 점 재클릭과 기존 확정 버튼을 함께 제공한다.

이전 v1.28.1 로컬 확인본 검증(2026-10-08, 후속 면적·지도 레이어 변경 전): 전체292개, 빌드·CSP·배포 파일 검사가 통과했다. 비공개 합성 범위로 실제 앱의 기록 열기→3D→기본 보고서5쪽 연결과 표준지도 타일 표시를 확인했다. 1:1/높이2배 전환은 방위·시점·줌 및 실제 수치를 보존했다. 375px 화면의 경사 비율·지도 버튼·지역명은 가로 넘침과 조작 버튼 중첩 없이 표시됐다. 주소가 정상 표시되면 큰 팝업의 자동 열기를 억제하고 핀 클릭의 상세보기는 유지한다. 갱신한 A3 이미지PDF는2쪽을 생성해 렌더링 검토했다. A4는 실제 인쇄CSS를 적용한194mm 폭의 확인 화면에서 범위 페이지 높이877px(인쇄영역1062px 이내)을 확인했으며 인쇄 대화상자의 최종 페이지 분할까지 검증한 것은 아니다. 이 결과는 앞선 작업 이력이며 아래의 최신 통합 검증과 구분한다.

### 후속 로컬 확인본 — 최신 검증(2026-10-08)

경사별 추정 면적·내용 크기에 맞는 지역명 배지·지명과 공개 지번 레이어·좌우 시점 이동·추가 확대와 거리 눈금까지 포함한 전체 검사는 **320/320 통과**했다. 현재 소스의 빌드·CSP·동봉 자산 검사도 통과했다. 빌드 통과를 새로운 배포 패키지 작성이나 공개 배포 완료로 해석하지 않는다.

- 지도 레이어 메뉴의 「地名（都道府県・市区町村）」는 기본 ON, 「地番（公開2024）」는 기본 OFF임을 실제 브라우저에서 확인했다. 공개 타일의 지역명과 지번 번호·참고 경계가 표시됐고, 레이어가 표시된 상태의 작도 클릭도 전달됐다. 공개 지번은 화면 참고용이며 검토 경계·면적에 자동 채택하지 않는다.
- 375px 화면에서 경사별 추정 면적과 선택 지역명 배지의 가로 넘침이 없었다. 지역명 배지는 짧은 이름에 맞춰 줄고 긴 이름은 제한 폭 안에서 줄바꿈한다.
- 경사 비율과 추정 ㎡를 함께 담은 A3 PDF 두 쪽을 생성해 렌더링을 검토했다. A3는 높이 강조 없는 1:1과 중앙의 고정 시점을 유지했다.
- 「視点の移動」에서 실제 좌우 드래그로 지형 둘레를 돌아 다른 옆면을 보고, 위로 드래그해 내려다보는 각도를 높이는 동작을 확인했다. 초기 시점 버튼은 처음 방위·시점각·줌으로 복귀하고 높이2배 선택은 유지했다. 경사 수치와 추정 면적도 조작 중 유지했다.
- 지도는19까지 확대하며 항공사진·표준지도는 원자료18 타일을 확대한다. 실제 지상 거리 계산을 유지한15m 눈금에서 공개 지번·경계가 표시되고 화면 오류가 없는 것을 확인했다. 이는 원자료의 정밀도 향상을 뜻하지 않는다.

이번 후속 변경의 **GitHub main 병합·공개 배포와 Mac/Safari 실기 확인은 미실시**다. 현재 공개 버전의 근거는 `DEPLOYED_VERSION.md`의 v1.28.0을 따른다. 공개 타일의 표시 확인과 실제 안건의 경계 정확도·등기·현장 측량 검증은 구분하며, 환경 간 기록 재개와 실제 필지자료 검증의 기존 미확인 범위를 완료로 바꾸지 않는다.

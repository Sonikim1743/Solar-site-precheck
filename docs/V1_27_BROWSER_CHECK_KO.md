# v1.27 브라우저 확인 — 2026-09-24

기존 사용자의 5173 기록을 변경하지 않고 별도 5273에서 합성 자료로 확인했다.

- 60,000kWh/년의 합성 검토 기록 읽기·적용 성공. 실제 발전량 API 조회를 대신한 수치는 아니다.
- 합성 GeoJSON 3필지 가져오기, 검색으로 1개 대상/1개 참고 선택 성공.
- 대상 면적 10,139.6m², 참고 필지는 합계 제외. 선택 전후의 발전량 60,000kWh 유지.
- 지도로 4점 검토 범위를 지정·확정·해제했다. 대상 필지와 겹치지 않는 범위는 0m²와 안내가 나왔다. 제외 영역의 겹침/차감은 단위 테스트로 검증했다.
- 새로고침 후 원본 전체 파일을 재가져오지 않아도 선택 필지 2개와 면적 복원.
- 기본 4쪽+발전량 1쪽+필지 요약 1쪽+출처 목록 1쪽으로 1~7 페이지 번호 확인. 지번 도형/범례와 월별 표 실제 화면 확인.
- 데스크톱에서 필지 요약/목록의 내용 높이는 각각855px/389px, scrollHeight와 clientHeight 일치. 실제 프린터 출력 검증은 아니다.
- 390px 화면에서 문서 scrollWidth375px, 필지 조작 영역 clientWidth/scrollWidth247px로 가로 넘침 없음. 화면 크기 검증 후 설정 복원.

실제 업무 토지 파일, 실물 프린터, Mac의 브라우저 환경은 별도 인수 후 확인 대상이다. 자동 테스트의 기하학·기록 유효성 검증과 브라우저에서 실제 조작한 항목을 구분한다.

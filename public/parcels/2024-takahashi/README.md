# 公開原本由来の地域地番

法務省2024年公開資料をAIGIDが変換した高梁市の公共座標5系SHPを使用。
[公式カタログ](https://www.geospatial.jp/ckan/dataset/aigid-moj-33209)。
原本資源 `6e1e7334-d2ce-4b20-ac7c-85dcdf4d58f0`。
カタログのライセンス表記はCreative Commons Attribution。

原本をWindowsで再取得し、`build/prepareRegionalParcels.mjs` で
備中町西山周辺の小地域を新たに処理した。Mac最終ファイルのバイト復元ではない。
原本358,670レコードのうち925筆。形状検証に失敗する16筆は選択を制限する。
各筆を一度だけ保存し、3個の小断片と筆別空間索引で照会する。
断片合計1,449,105 bytes、索引193,220 bytes。新しいIDは原本SHAと
原本レコード番号から生成する。図形の切り取り・簡略化・修復を行わない。

原本のSHA-256：
`1317873169bd31fdda886f17b7244c652ef06419ce54aa292a1ddadfa39fce85`。
原本の年・CRS・出典・原本レコード・部分数・穴数をindexに残す。
現在の準備範囲外は未準備。全国のPMTiles表示を全筆の確定形状に代用しない。
原本由来でも最新登記・測量で確認した筆界ではない。

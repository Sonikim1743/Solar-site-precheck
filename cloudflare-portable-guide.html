Solar Site Precheck 配布ガイド

v1.28.1 / 2026-10-08。Windows更新用の release_light.zip とCloudflare公開用の cloudflare.zip は別パッケージです。最新の配布状態とハッシュは 公開記録、詳しい手順は 配布案内を参照してください。

Portable版を更新する場合

  1. 既存のSolar Site Precheckフォルダを開きます。
  2. UPDATE_APP_FROM_RELEASE.cmd を実行します。
  3. 起動後、画面下部の「実行環境・API診断」でVersion / Build / API状態を確認します。

Cloudflare Pagesへ反映する場合

Cloudflare用ZIPを展開したルートで、認証済みWranglerを使って以下を実行します。

pnpm dlx wrangler@4 pages deploy dist --project-name solar-site-precheck --branch main

展開先の同階層に dist・functions・shared・wrangler.toml が必要です。Windows更新ZIPやdistだけではFunctionsを含む公開になりません。GitHubへのpushとPages公開は別工程です。

機能差の目安

  • Cloudflare Pages: HTTPSで安定公開。NEDO APIはFunctionsで利用可能。相続PDFサーバー解析はPortable / Local版を使用してください（Cloudflare側の /api/inheritance-pdf は誤ってHTMLへフォールバックしないための明示的な未対応応答です）。
  • Portable / Local: NEDO APIと相続PDFサーバー解析をローカルNodeで利用可能。PDF目安サイズは80MB。
